2. `docs/PROJECT_STATE.md`、`docs/任务编排.md`：当前事实、任务边界与证据；历史测试记录不作为当前验收。
3. `docs/00-架构裁决与底座说明.md`、`docs/01-AIRI复用与裁剪清单.md`、`docs/02-技术适配声明.md`，以及当前任务对应的阶段手册。
4. 先理解现状，再修改；不先重构再理解，不读取或回显凭证来证明配置存在。

## 1. 产品与执行职责

- Aimy 是虚拟情感陪伴产品，桌面角色是呈现方式；优先陪用户打游戏、看视频。
- 输入为文字、连续语音、用户分享图片、授权屏幕；语音必须支持插话打断。声音、口型、表情与动作需要协调。
- 情感陪伴可以发展亲密关系；恋爱阶段和好感数字是辅助机制。
- 默认 macOS、一个官方 VRM 角色、本地优先、无摄像头；少量受邀用户自行配置模型服务（BYOK）。一期不做露骨内容。
- 按 A 工程基线 → B 关键体验验证 → C 桌面文字/图片切片 → D 实时语音/看屏/表现/隐私 → E 连续陪伴/试用推进。
- 研发负责代码、集成、适配和验证；产品负责人判断体验和资产方向。已确定的产品决策不重复询问，先完成授权范围内可审阅的工作。

## 2. 强制底线

1. 密钥不进入仓库、安装包、静态前端资源、截图、日志或提交。BYOK 凭证的运行时存储与进程边界必须明确，不能承诺客户端能隐藏平台密钥。
2. 会话、关系、已确认记忆和设置必须可恢复；写入、重启、纠正和删除分别提供证据，未实现时写待验。
3. 模型建议与结构化输出先校验；处理超时、失败和有限重试，取消后拒绝陈旧输出。异常内容统一脱敏，不向用户展示内部堆栈。
4. 权限、关系值、持久化由确定性代码维护；模型不能自行打开采集或执行高风险操作。电脑自动操作、外部发信、支付不在一期范围。
5. 屏幕和麦克风独立授权，默认关闭；关闭、隐藏、退出要停止已有采集并拒绝新调用，界面明确状态。原始截图和录音默认不长期保存。
6. 一期情感陪伴、不做露骨内容；落实未成年人基础保护与危机/自伤兜底。
7. 模拟传输、假设备和测试通过不代表真实模型、真实设备或用户体验已通过；无真实验证条件如实写待验。
8. `../airi-main` 为只读参考库。按消费闭包接入源码并保留来源、许可证和原测试，不删除参考库功能以缩小产品范围。
9. 不为对齐模板目录整体重构，不引入需求未触发的功能。游戏、云同步、订阅、自建角色与电脑自动操作后置；一期无摄像头。

## 3. 开发与协作

- 产品规则放领域模块或薄适配层；继续复用 AIRI Agent、provider、音频、VRM、桌面和会话能力。
- 任务明确目标、改动边界、验收标准和证据；先让一条真实链路可用，再扩展能力。
- 需要并行协作时，给每个 Agent 明确文件所有权、接口、禁区与交付；集成负责人统一验证。
- 尊重父仓库已有暂存内容；建立可恢复基线后小步修改，不擅自清理、重置或重写历史。
- 正式角色/音色需记录来源和许可；AIRI 示例素材或占位演示不计为 Aimy 正式资产。

## 4. 任务出口

| 项目 | 记录要求 |
|---|---|
| 范围 | 已完成、未完成及原因；不把后续路线写成当前完成 |
| 自动化 | 与改动相关的测试/构建/类型检查命令和实际结果 |
| 真实链路 | 模型、设备和目标 macOS 验证；不适用与未验证分开 |
| 数据与隐私 | 本任务涉及时验证重启、删除、取消、关闭采集及异常脱敏 |
| 产品体验 | 用户体验验收和自动化证据分别记录 |
| 文档 | 更新启动与验证说明、项目状态及决策入口 |

任务技术出口满足不等于整个阶段或 MVP 完成。涉及未接入能力的验收写“尚未实现/待验”，不要用空表或全绿断言代替证据。

## 5. 决策记录

产品决策写入 PRD，进度与验证写入 PROJECT_STATE，任务写入任务编排。只询问尚未授权、且会实质改变产品或风险的选择；资产风格评审不阻塞工程基线及已授权的可行性验证。
