# 06 · 连续语音与拟人表达

> 当前需求：[PRD-MVP-重构版.md](PRD-MVP-重构版.md)。连续语音与用户插话打断是核心体验，先做 B 实验，再在 D 集成；官方音色尚待方向、授权和真实链路验收。

## 1. 目标与基础

复用 AIRI VAD/ASR、音频管线、provider、TTS/播放与 VRM 口型驱动。AIRI 有停止/取消等基础接口，但已有桌面路径在角色播放时抑制输入；不能据此宣称自然插话已经完成。

文字的口语化、TTS 表现力、流式播放、对话轮转和回声处理共同决定自然度。停顿/呼吸既可能由文本或标记引导，也依赖合成模型能力，不简单等同于加语气词。

## 2. 必须跑通的链路

用户音频 → VAD/识别 → 多轮会话 → LLM 增量 → 分段/流式 TTS → 播放/口型/表情动作。

用户在角色说话时插话 → 判断有效输入 → 停止旧播放并取消旧合成/相关生成 → 识别新输入 → 新回复。请求标识隔离迟到结果，旧音频不得重新播放；取消与错误后角色回到可交谈状态。

- 同时验证耳机和扬声器，避免角色自己的声音反复进入识别。
- 记录连续输入、重叠说话、背景噪声、设备切换、权限关闭/撤销。
- 麦克风关闭后停止输入；权限拒绝不循环弹窗；TTS 失败保留文字，ASR 失败可打字。
- 表情、口型、语气和动作接收统一的经校验表现信号，不仅增加表情数量。

## 3. Provider 与音色

用户 BYOK，聊天、ASR、TTS 与视觉分别配置并验证；聊天接口可用不代表具有语音能力。沿用 AIRI provider，不在 Aimy 重造厂商 SDK。

按中文自然度、流式能力、首声时间、情绪表达、区域可用性、许可和实际成本选择有限可用组合。未测不填写质量或费用结论；未获许可不克隆真人声音，不把示例音色当正式授权。

## 4. 验收证据

| 场景/指标 | 记录 |
|---|---|
| 语音响应 | 输入结束、识别完成、首 token、首音频及播放开始耗时 |
| 用户插话 | 从有效输入到旧播放停止，新输入是否完整，是否出现旧回复回流 |
| 回声/设备 | 耳机、扬声器、噪声与设备变化的成功/失败案例 |
| 表现协调 | 口型、声音、表情和动作录屏与人工评分 |
| 隐私/降级 | 关闭后无采集/新调用，单服务失败仍有清晰可用交互 |

先测基线再定阈值，不能把模拟播放或单次问答写成连续实时语音已验。详细执行见阶段手册 B 与 P4。
