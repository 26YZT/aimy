# 00 · 架构裁决与底座说明

> 当前产品定义以 [PRD-MVP-重构版.md](PRD-MVP-重构版.md) 为准。本文说明复用依据，不作为全功能完成或生产验收声明。

## 1. 裁决

**基于 AIRI 二次开发，延续 Electron、Vue、Agent、provider、音频与 VRM 体系。** AIRI 已有大量实现和扩展点，能够减少基础建设；Aimy 的实时互动、可打断语音、连续人格、记忆与主动陪伴仍需适配和实测。

旧版“AIRI 能实现全部需求且所有核心能力生产级”的断言撤销。包存在、测试通过、官方演示、真实产品能力是不同证据层级。

## 2. 复用理由与缺口

| 部分 | 可复用基础 | 必须核验或补齐 |
|---|---|---|
| Agent/provider | 流式运行时、hook/context、模型适配与取消 | 多轮产品会话、异常脱敏、真实模型与时间基线 |
| 桌面/VRM | Electron 入口、角色卡、渲染与表现驱动 | 最小消费闭包、官方资产、窗口与表现协调 |
| 音频/视觉 | ASR/TTS 管线、捕获与视觉工作负载 | 插话、回声、连续输入、屏幕回应及时性 |
| 连续陪伴 | 关系领域原型、协议与事件挂载点 | 主动不打扰、记忆纠正/删除、恢复、隐私控制 |

## 3. 一期技术与数据边界

- macOS Electron + Vue 3 + TypeScript，用户自行配置模型服务。
- 不新增默认后端，不改用另一套模型 SDK，不为模板目录重构。
- 本地 AIRI 会话链路使用 IndexedDB；`duckdb-wasm` 与 `drizzle-duckdb-wasm` 目录只含迁移说明。
- Aimy 存储适配以实际源码与重启恢复为依据，为会话、设置、关系、记忆明确写入责任；当前接口原型不能算持久化已验。
- 屏幕/麦克风默认关闭、独立授权；关闭/隐藏/退出终止采集，权限由确定性代码维护。

## 4. 目录与执行边界

`../airi-main` 为只读参考；`digital-lover` 为产品工作区；Blueprint 提供方法与工具，其测试不计 Aimy 产品完成度。既有包不重复导入，新消费包先检查闭包、许可证与平台限制；当前桌面新增消费包见复用清单和修订记录。

当前按 A 工程基线 → B 关键体验 → C 桌面切片 → D 实时感知 → E 连续陪伴与受邀试用推进，详见任务编排。独立游戏、云同步、订阅、自建角色与电脑自动操作后置，未来技术栈不提前锁定。

## 5. 底座现状的解释

`relationship-engine` 是可运行的领域原型，阶段和好感数值服务于情感体验；尚不能视作已接入产品与持久化。`companion-engine`、`memory`、`avatar-fitting` 为接口占位；后者属于后置范围。

历史 Core Agent 147 项与关系引擎 8 项记录只证明对应测试范围，最新构建、类型检查与验收见 PROJECT_STATE。
