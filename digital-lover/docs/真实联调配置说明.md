# Aimy 真实联调配置说明

目前用户尚未配置模型服务。原型已提供三个设置页，可以按下面的接口能力准备；服务商和模型可不同，密钥直接在本机窗口填写，不发到聊天中。保存配置不会自动请求模型或开启采集。

## 需要的四类能力

| 能力 | 当前原型要求 | 设置页/需要填写 |
|---|---|---|
| 对话 | 中文多轮、流式Chat Completions或Responses，接收历史上下文 | 对话与识图：API基础地址、协议、对话模型、密钥 |
| 图片理解 | 相同服务地址/协议/密钥下可接收JPEG/图片输入；用于分享图片和选源看屏 | 对话与识图：识图模型；留空使用对话模型，前提是它支持视觉 |
| 中文ASR | OpenAI兼容HTTP转写接口，接收multipart WAV并返回JSON文本；当前是短片段，不要求WebSocket | 语音识别：API基础地址、识别模型、独立密钥 |
| 中文TTS | OpenAI兼容HTTP合成接口，接收text/model/voice，支持返回WAV；音色ID须可用 | 语音合成：API基础地址、合成模型、音色ID、独立密钥 |

地址填API基础路径，例如服务商给出的`https://api.example.com/v1/`，不要填完整单次请求路径、带凭证或查询参数的URL。当前界面的识图模型与对话模型共享服务地址和密钥；如果服务分属不同平台，需要先调整适配，再联调，不假定名称兼容就能调用。

同一密钥可由用户明确分别填入三个设置页，程序不会自动借用对话密钥。三个设置页保存后输入会清空，重新打开不会回显密钥。凭证由主进程调用safeStorage加密；真实请求内容发送给所配置的服务。本地记录不代表外部服务没有处理内容。

可以先提供这份非敏感信息用于核对适配：服务商、对话模型、识图模型、ASR模型、TTS模型/音色ID、支持的接口协议。模型只支持专有WebSocket或只输出MP3时，当前适配不能直接使用，需根据其正式文档增加适配。

## 联调顺序和记录

1. 配置对话/识图，发文字、分享获准图片；验证回复/相关性、取消、失败提示和新进程恢复。
2. 配置ASR/TTS，戴耳机后显式开麦克风和朗读；检查持续说话、角色说话时插话、短声/噪声与旧回复停止。请求可能产生所配置服务的费用。
3. 切换扬声器，记录回声误识别、重叠讲话和设备切换。当前250ms确认与分段替换策略需据实测调整，不能把“有文字返回”当成自然交流验收。
4. 主动选择获准测试窗口/屏幕，检查画面回应；关闭看屏后观察无新请求和旧观察回流，隐藏/重显/重启后采集仍关闭。
5. 记录ASR、首token、首声、插话停止、视觉反馈各段耗时与失败例，并做30分钟稳定性/内存观察。结果另附真实链路记录，不混入假设备通过数字。

麦克风、朗读和看屏都由用户显式开启；相应服务未配置时不采集。看屏只共享画面，不录系统音频；无摄像头。画面约5秒最多分析一次，忙时/相同帧跳过；原始录音和帧不长期保存，转写和观察文字会进入本地对话。
