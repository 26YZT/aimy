# B 技术手册：关键体验可行性验证

> 承接已批准 B 阶段；在 A 基线后、C 桌面产品集成前验证难点。`airi-main` 保持只读，实验适配/记录放产品工作区，不把实验改动写回参考库。

## 目标

提前判断 AIRI 链路能否支持 Aimy 所需的连续交谈、用户插话、回声处理、流式播放/口型协调，以及游戏/视频画面的及时反馈。产出真实耗时、成功/失败例及剩余缺口，不把源码接口视作已实现体验。

## 语音实验

- 核对 VAD/ASR、播放、合成、取消与桌面输入抑制的真实连接方式，建立原行为基线。
- 角色说话时仍可发现有效用户输入；插话停止旧播放，取消旧合成/相关生成，迟到结果不得重新播放。
- 用请求标识或既有运行时机制隔离旧输出；新输入接续会话，角色回到可回应/待机状态。
- 分别测试耳机、扬声器、用户与角色重叠说话、背景噪声、短插话及设备切换；记录回声误识别和漏识别。
- 记录输入结束→识别完成→首 token→首音频、插话→播放停止以及口型/播放取消的表现。

## 看屏实验

- 核对捕获、采样节奏、视觉请求和上下文注入；画面是观察数据，不是模型指令。
- 使用获准测试画面，包含稳定页面、游戏事件和快速视频变化；记录采样到理解/回复的耗时与错过事件。
- 关闭采集后禁止新请求和屏幕来源回应；旧结果不能重新开启陪伴动作。
- 不默认长期保存原始截图；测试证据使用脱敏画面，明确外部 provider 的发送范围。

## 实验出口

| 证据 | 要求 |
|---|---|
| 自动化 | 假 provider/设备的取消、陈旧结果、权限关闭负例 |
| 真实链路 | 已有合法配置下的真实模型/设备实测；无条件则明确待验，不替代为模拟 |
| 时间与质量 | 分段耗时、耳机/扬声器对照、画面相关性、口型同步和失败例 |
| 可行性 | 可直接复用、需要适配、尚不可行分别记录，并给 C/D 接入范围 |

先测量再定体验阈值，不提前承诺“真人级”。B 是可行性验证，不是完整隐私、正式资产、安装包或产品验收。
