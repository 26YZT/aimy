# P0 技术手册：已批准产品基线与资产准备

> 产品方向与 A–E 路线已于 2026-10-07 获批，见 [PRD-MVP-重构版.md](../PRD-MVP-重构版.md)。本手册用于维护基线和准备资产评审，不重复索取已批准范围授权。

## 目标

产品主线是有形象、声音、人格与记忆的虚拟情感陪伴；桌面呈现，游戏/视频陪伴优先。文字/图片、可插话的连续语音和授权看屏均进入产品目标。

## 工作与交付

1. 维护统一 PRD、任务与状态入口；历史材料标注范围与失效结论。
2. AIRI 能力矩阵分别记录源码存在、已接入、模拟验证、真实链路与人工验收，不用“生产级”代替证据。
3. 把启动/配置、文字/图片、语音插话、看屏、主动陪伴、关闭权限、重启、纠正/删除记忆拆成用户验收旅程。
4. 准备一个官方角色的人设/画风/动作/声音方向、界面占位与来源许可清单，明确占位资源。
5. 维护性能/成本实测空位，不填写虚假耗时或费用；保留可恢复的源码与 Git 暂存基线。

## 验收与边界

用户已确认 macOS、一个官方 VRM、本地优先、无摄像头、BYOK 受邀试用及 A–E 顺序。第一角色的具体人设/视觉/声音、正式资源授权与界面方向待评，A 工程基线和 B 可行性验证可以继续。

若后续提出游戏优先、云端或商业模式改变，按新产品决策修订总纲；不让旧 M 路线自动扩大当前范围。需求批准、资产方向认可与 MVP 完成分别记录。
