# P4 技术手册：D 实时语音、看屏、表现与隐私

> 承接 D 阶段；基于 B 的实验结论与 C 多轮会话。连续语音、插话和关闭采集是验收能力，不能降为一次问答。

## 技术边界

- 复用 AIRI 音频/VAD/ASR/provider/TTS 与播放；持续输入、有效插话、回声处理和旧请求取消一起接入。
- 复用 AIRI 屏幕捕获和 vision workload；只有应用开关、系统许可、会话状态均有效时才采集必要帧。
- Electron 管系统授权和捕获生命周期，Vue 展示状态，Agent 调用前复查门禁；不能只隐藏按钮。
- 语言、声音、口型、表情与动作协调，停止播放/失败/取消后回到有效状态。
- 聊天、ASR、TTS、Vision 分别配置和验证；单服务失败保持可理解替代交互。

## 任务与证据

1. 屏幕/麦克风独立授权、默认关闭、外部发送说明与状态指示。
2. 连续语音与可打断播放，隔离迟到生成/合成；耳机、扬声器、重叠讲话、噪声与设备变化实测。
3. 授权游戏/视频测试画面理解，整合上下文，记录采样、视觉和回应耗时与漏事件。
4. 语音/口型/表情/动作录屏和人工一致性评分。
5. 拒绝、撤销、关闭、隐藏、退出和错误恢复负例；旧 stream 终止、不启动新采集或未经授权调用。
6. 假设备/provider 测试、真实模型/设备与目标 macOS 结果分别记录。

## 出口

用户可连续交流，被打断后停止旧语音并接住新输入；对画面产生相关回应。关闭任何采集都真正停止，不出现旧结果触发的幽灵回应；TTS 失败仍可看字、ASR 失败可打字、看屏失败仍能聊。

性能先测基线再锁目标。原始屏幕帧/音频默认不长期保存，异常不泄露内容/凭证/堆栈。没有真实设备与模型证据时该出口为待验。
