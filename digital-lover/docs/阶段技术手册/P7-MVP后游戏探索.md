# P7 技术手册：MVP 后游戏垂直切片

> 状态：探索项，不纳入桌面 MVP 完成条件；先验证再决定是否立项完整游戏。

## 假设

同一 aimy 角色进入简单 3D 场景后，能理解玩家和世界状态并自然行动，同时保留身份、关系和记忆。

## 技术路线

- 游戏引擎暂不预设。以“雪夜庭院 + 一个角色 + 三种行动”为最小场景，对比浏览器 Three/Tres、Godot 等候选在 AIRI 桥接、VRM 资产、平台、延迟和 AI 控制上的总成本。
- AIRI Core Agent/角色卡/记忆/关系继续作为共同大脑；游戏只暴露白名单工具和结构化事件。优先检查 AIRI Spark command/notify/context 协议与游戏集成源码。
- 反射级交互由游戏本地规则即时响应；长句交流和复杂意图交给模型，避免每个动作都等云模型。
- 隔离游戏场景状态与桌面隐私权限；进入游戏不等于自动打开看屏和麦克风。

## 交付与验收

1. 引擎和资产适配矩阵，包括真实启动测量和许可证。
2. 场景可运行：玩家进入，角色注意到玩家、对话、完成三种白名单行动。
3. 场景事件→AI 决策→动画/语音→世界状态更新的端到端时延记录。
4. 离开游戏后同一角色的身份、关系和已确认记忆仍保持。
5. go/no-go：不达标时保留试验，不宣称进入完整游戏开发。

本切片不做开放世界、多人、复杂战斗、订阅、海量 NPC 或让模型直接控制所有游戏对象。
