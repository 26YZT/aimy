# P2 技术手册：A/B 同期的角色与界面原型

> 产品方向已批准；具体角色、声音和视觉仍需可审阅材料及评审。A/B 不因资产未定而停止，C 的正式资源与交互应依据原型结论。

## 目标

让用户评价启动/配置、一个角色、桌面对话和看屏/听声状态。原型可以使用明确标注的假数据和占位资源，不能计为真实 AI、设备或正式美术交付。

## 方法与任务

1. 按已批准旅程做启动、角色配置、桌面陪伴/聊天三类关键屏幕，沿 Vue/AIRI UI 体系准备可运行样机。
2. 设计实施前取得有来源的参考，记录选择依据；界面状态包含文字/图片输入、流式取消、授权/关闭、安静、缺配置与服务失败。
3. 只准备一个官方角色的概念：人格、比例、画风、服装、待机与情绪；不扩大为角色池或用户捏人。
4. 整理 VRM、动画、声音、字体/图标来源和许可；未获授权不作为正式资源，不擅自克隆音色。
5. 在目标 Mac 尺寸上检查桌面遮挡、状态可读、角色/聊天占位；区分 mock 与实测。

## 出口

产品负责人认可一套角色/界面方向，正式模型与声音许可仍分别核验。角色表现由资源和运行时驱动共同决定，必须在 AIRI stage-ui-three/音频链路实测。具体资产未定时交清晰缺口，不宣称美术完成。
