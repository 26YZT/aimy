# P5 技术手册：E 连续陪伴、人格与记忆

> 承接 E 的连续陪伴部分；依赖 C 会话与 D 隐私门禁。重点是持续相处体验，恋爱阶段/好感数字为辅助机制。

## 分工与数据流

AIRI hook/context/角色卡提供会话与人格入口；产品领域模块维护主动决策、情绪/关系和记忆。观察 → 权限 → 安静/频率/冷却 → 允许发言 → Agent → 安全/人格检查 → 表现 → 会话/关系事件/候选记忆。

- companion-engine 由确定性规则先决定是否打扰，模型只生成语言与语气；每次触发或沉默有不含敏感原文的原因记录。
- relationship-engine 保留原型和测试，接事件来源、校验与快照保存；模型不能随意写好感值。
- 人格与情绪分离，情绪有原因、可恢复，统一影响语言/声音/表情/动作。
- memory 先实现少量经确认的事实/偏好及相关检索，纠正/删除/恢复；向量方案按真实需要决定，不默认搬云端 pgvector。

## 任务与出口

1. 安静模式、搭话频率、冷却与忙碌判断，关闭看屏后不再出现屏幕来源搭话。
2. 人格跨轮一致、情绪与表现一致、关系事件可追溯并恢复。
3. 记忆查看、来源、纠正、删除与新进程重启；无关内容不强注入，旧值不在纠正后继续优先。
4. 假时钟/事件/存储负例与真实长期会话分别验证；用户评价连贯性、自然度与打扰度。

安静模式零主动发言、隐私关闭有效、关系与已确认记忆可恢复且可纠正删除才能通过。接口不再抛 TODO 只是起点，不替代产品验收。
