# 07 · 游戏方向（MVP 后探索）

> 一期包含陪用户打游戏、看视频：授权理解画面并回应。角色进入游戏执行操作、独立游戏世界均后置，不纳入当前 MVP 完成条件。

## 1. AIRI 的参考价值与边界

AIRI 的 Minecraft/Factorio 等是专门集成，可参考感知、反射、规划、行动分层及 Spark command/notify/emit/context 事件桥。它们不能自动转为所有游戏可用，也不能证明 Aimy 已具备游戏代理。

即时反应可由游戏本地规则处理，复杂意图交给模型；实际动作支持、时延、工具权限与游戏版本兼容均要逐游戏实测。旧版“毫秒级/秒级”是架构意图，不是本项目性能验收。

## 2. 与 Aimy 的边界

| 部分 | 当前基础 | 后续验证 |
|---|---|---|
| 人格与会话 | AIRI 角色卡、Agent/provider | 同一角色跨桌面与游戏的一致性 |
| 情绪与关系 | 关系领域原型，产品映射待接 | 事件来源、表现、保存与恢复 |
| 记忆与主动陪伴 | Aimy 接口占位 | 先完成桌面闭环，再消费游戏事件 |
| 游戏桥 | AIRI 协议与集成源码 | 白名单行动、失败处理、真实游戏执行 |

进入游戏不等于打开屏幕或麦克风授权。权限与场景状态隔离，模型不得直接控制任意游戏对象或用户电脑。

## 3. 后续探索出口

MVP 通过后再单独评审小场景，例如“雪夜庭院 + 一个角色 + 三种白名单行动”。场景只是候选假设；引擎、范围和正式游戏 PRD 未批准，不预设完整游戏制作计划。

验证源码桥接、资产兼容、许可、真实启动及事件到动作/语音的耗时；不达标保留实验并给出 go/no-go，不以演示宣布完整游戏开发完成。详见 P7 手册。
