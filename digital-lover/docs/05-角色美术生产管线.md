# 05 · 角色美术生产管线

> 本文是一个官方 VRM 角色的资源生产与联调方法。正式资源尚待方向、来源和授权验收，不代表当前已有产品资产。

## 1. 核心认识

拟人表现由**资源能力、程序驱动、模型输出和交互调度共同决定**。表情变形、骨骼、口型与动画是资源基础；眨眼时机、视线、口型驱动、平滑切换、动作混合和打断后的恢复在运行时完成。

旧版“全部效果在模型制作阶段做进模型、程序只加载播放”的说法作废。美术和代码并行，但必须在真实 AIRI 渲染/音频链路中联调。

## 2. 生产与接入流程

| 步骤 | 产出 | 联调检查 |
|---|---|---|
| 1 概念与人格 | 人设、画风、比例、服装、配色、声音参考 | 产品负责人认可统一气质 |
| 2 来源与授权 | 制作/采购方案、来源和许可记录 | 修改、再分发、商用、署名限制清晰 |
| 3 模型与材质 | 模型、贴图和材质 | 目标 macOS 加载、性能和透明材质 |
| 4 绑定与变形 | humanoid 骨骼、表情、眨眼与口型 | AIRI 驱动兼容，无错误映射 |
| 5 动画与表现 | 待机、说话手势和基础情绪动作 | 与表情/视线混合，不互相覆盖 |
| 6 语音与人格联调 | 合法音色、语气与停顿方式 | 中文、流式播放、口型、插话停止一致 |
| 7 导出与回归 | VRM/动画版本及资产清单 | 重新加载、缺资源提示、取消与恢复 |

可使用 VRoid/Blender 等现有工具，但导出成功不代表在产品中即用。工具与供应商按实际制作需求选择；不在此预定新的采购或费用。

## 3. 最小正式资产验收

- 一个 VRM，角色人格卡与音色配套；基础骨骼、口型、眨眼和可区分情绪可用。
- 至少一种待机表现，角色说话、被打断和重新待机时无僵住/持续张嘴。
- 产品负责人认可视觉、语言、动作和声音的一致性；相关资源许可记录完整。
- 文件版本、来源、用途、授权状态与缺口可追溯；占位与正式资源分开标注。

`avatar-fitting` 和用户导入模型属于后置范围。自动映射只能帮助适配，不能补出不存在的优质表情、骨骼或动画。

## 4. 下一步

先准备第一角色的可审阅概念与声音参考，再制作/采购正式资产；不擅自生成图像或克隆音色。A/B 工程与可行性验证继续进行，资产未定不冒称美术交付完成。
