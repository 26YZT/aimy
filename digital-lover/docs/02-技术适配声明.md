# Aimy 技术适配声明

> 当前需求以 [PRD-MVP-重构版.md](PRD-MVP-重构版.md) 为准。Blueprint/starter kit 作为工程纪律与验收方法参考，代码底座使用 AIRI；旧 starter kit 目录不作为必读前置。

## 1. 产品形态

虚拟情感陪伴产品，桌面角色呈现；游戏/视频陪伴优先。多轮文字/图片、可打断连续语音、授权看屏与形象反馈构成持续交互。少量受邀用户 BYOK，macOS、一个官方 VRM、本地优先、无摄像头。

## 2. 技术路线与适配

| 层 | 当前路线 | 原因与限制 |
|---|---|---|
| 桌面/前端 | Electron + Vue 3 + TypeScript | 延续 AIRI stage 体系；先验证真实消费闭包 |
| Agent/provider | AIRI core-agent/provider-inference | 不另造 Agent loop 或厂商 SDK；供应商能力分别验证 |
| 包管理/测试 | pnpm workspace、TypeScript、Vitest，按需桌面 smoke | 工作区依赖必须声明完整，测试边界不得外推 |
| 数据 | 核验并适配 AIRI IndexedDB 会话链路 | 本地 DuckDB 目录为迁移说明；恢复/删除未验不能说通过 |
| 部署 | 目标 macOS 安装与受邀试用 | 沿用可复用打包能力；签名/公证依据实际分发验收 |
| 后端与向量检索 | 不作为一期默认依赖 | 云同步/订阅后置；记忆先验证本地最小闭环 |
| 设备能力 | 屏幕与麦克风独立授权 | 插话、回声、权限关闭和设备差异必须实测 |

## 3. 工程底线的验收地位

以下是**要求与待核验项**，不声明全已通过。当前实际结果在 PROJECT_STATE 与证据中维护。

| 要求 | 验收证据 |
|---|---|
| 凭证与内部错误不外泄 | 配置边界、异常脱敏回归、产物检查；外置配置本身不是证明 |
| 重要数据可恢复 | 新进程重启后会话/关系/记忆恢复，纠正与删除生效 |
| 校验、超时、取消及有限重试 | 畸形输出、网络失败、陈旧结果和 SDK 初始化异常测试 |
| 隐私边界由代码维护 | 关闭/拒绝/隐藏/退出后无新采集，旧 stream 终止 |
| 真实模型与设备验证 | 与模拟 provider/假设备结果分开；缺条件标待验 |
| 人工体验认可 | 产品负责人及受邀用户的自然度、相关性、打扰度评审 |

AIRI 的类型/协议/函数存在不自动证明 Aimy 隐私、持久化或错误处理正确。旧版“全部已通过”表作废，不改变历史测试数字。

## 4. 约束与下一步

先按 A 修复工程基线、统一异常边界并保留可恢复源码版本，再做 B 关键体验实测。正式角色人设/视觉、VRM/动画许可、声音风格/合法音色及界面方向待评；这些不阻塞 A/B 已授权工作。

BYOK 客户端仍有运行时凭证可见风险，应明确存储与进程边界、外部发送内容，不承诺在桌面包内隐藏平台密钥。游戏、云同步、订阅、自建角色和电脑自动操作后置，不提前锁定其技术架构。
