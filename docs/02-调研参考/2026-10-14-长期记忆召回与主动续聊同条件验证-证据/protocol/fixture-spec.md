# 同条件离线记忆、召回、续聊协议

2026-10-14，用户授权的研究验证，未授权产品实施。主写者冻结输入后worker只读；所有新增实验只写各自/tmp目录。AIRI是当前aimy-app固定源码，候选AionsHome/Ryza固定本地源码。不读取真实配置、聊天、密钥、浏览器用户数据；不安装、不联网、不发真实消息。

共同条件：Asia/Shanghai、2026-10-14T10:00:00+08:00、同一合成中文消息/事实/查询/事件序列、相同固定模型输出、无embedding；语义同义查询单独当能力边界，不能用人工embedding把答案编码进去。检索最多5项、上下文目标1200字符；只用原实现支持的参数，不为达目标偷偷给缺失的一方补排序、过滤、截断或存储。

可做字段名称/时间格式转换、固定IO替身与原模块装配；须逐项登记真代码、替身、转换、原生缺失。对不等价接口记unsupported，不伪造差异分数。案例expected是产品期望，不是“通过”既定结果；缺陷断言符合预期仍是产品合同fail。

长期记忆固定抽取是控制变量，不证明抽取理解正确。来源引用白名单与来源含义正确是两回事。新对象、新VM、新OS进程、新浏览器进程分别标明。真正持久化用隔离合成库；不能给原内存manager加落盘再称AIRI已支持。

召回保留原候选排序；记录原输出、选择ID、source可追溯、无关命中、重复、预算和独立gold命中，不以整个历史包含答案冒充相关事实召回，也不把未匹配能力记为零分而生成总排行榜。没有真实模型答案评分/自然度/召回理解AB。

续聊用假时钟/固定生成输出/记录器，原调度与取消/去重代码实际执行；不发信。记录何时计划、领取、提交、撤销；进程恢复用同一隔离库。关闭开关、新用户回归、切会话、在飞关闭分别测试，claim通过不等于整个可见发言成功。

输出：README、源码哈希、可重跑脚本、机器results（逐case原始观察+期望+contract_outcome+边界）、差异裁决。不得把不同层次计数相加成产品通过率。待真实模型/设备/人测留待验证。
