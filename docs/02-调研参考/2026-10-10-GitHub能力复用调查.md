- 先保留 AIRI 原本的界面、渲染、角色与已有音频链路；本轮不足以证明应整体替换其对话引擎。下述接入成本是根据语言/部署边界的工程推断，待与 AIRI 运行审计交叉验证。

## 五个深读候选

### 1. Mem0：最贴近薄记忆适配层的候选之一，需补确定的“纠正/忘记”语义

- Python和TS库、独立自托管服务、云平台是不同路径。当前TS OSS源码里的MemoryVectorStore虽然名字叫memory，实际使用better-sqlite3磁盘数据库；可以设明确dbPath，默认路径在用户目录.mem0。意味着有跨进程持久化设计，不等于重启召回已测试。TS实现不需要为了最小本地实验先部署独立数据库服务；引入原生SQLite绑定要处理Electron ABI与打包。[库/云/服务区分](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/README.md)、[SQLite向量存储](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/mem0-ts/src/oss/src/vector_stores/memory.ts#L40-L66)、[默认文件路径](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/mem0-ts/src/oss/src/utils/sqlite.ts#L5-L7)、[依赖](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/mem0-ts/package.json)
- SDK源码确有update、delete、deleteAll、history。自动add新算法是ADD-only，不会自动覆盖旧事实；明确纠正可以走update，但当前值选择仍需产品策略。[CRUD源码](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/mem0-ts/src/oss/src/memory/index.ts#L1653-L1789)、[新算法说明](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/README.md)
- 删除向量后，deleteMemory仍将旧内容prevValue写进history，实体索引清理异常只警告；因此“从回答中不再使用”和“完全清除该事全部副本”不能混用一个SDK delete的结论。history可追踪SDK修改，但原始对话、说话者、消息ID仍应由Aimy显式保存/关联，不能假定SDK history就是完整来源证据。[删除与历史](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/mem0-ts/src/oss/src/memory/index.ts#L2018-L2045)、[修改历史](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/mem0-ts/src/oss/src/memory/index.ts#L1953-L2013)
- README明确榜单分数来自带私有优化的托管平台，OSS不能照搬数字；未复现任何中文/伴侣记忆效果。默认模型/embedding可能上云，local SQLite只表示存储本地，须核对LLM/embedding配置与网络行为。[原文](https://github.com/mem0ai/mem0/blob/b7ad69afda6b6ed030347c66d48a13e4de9dec08/README.md)
- Aimy接入推断：中等；Electron主进程/本地服务适配，renderer只经现有IPC读取。至少追加source_message_ids、speaker、事件时间、确认状态、当前/过期标记和确定性置顶事实，避免将角色臆造内容当用户事实。

### 2. Graphiti：时间变化和来源结构清楚，部署/运行边界较重

- Python>=3.10；默认Neo4j，提供FalkorDB、FalkorDBLite、Neptune等后端选项。当前pyproject将Kuzu标为上游停止维护并将移除，不能照搬旧教程选Kuzu；FalkorDBLite选项需Python>=3.12。可经Python服务向AIRI TS提供HTTP适配，增加服务生命周期和数据库备份/升级负担。[依赖与后端](https://github.com/getzep/graphiti/blob/a9ef13f7e2cce23e92abd2f76947f42e270da25a/pyproject.toml#L12-L40)、[官方REST服务](https://github.com/getzep/graphiti/blob/a9ef13f7e2cce23e92abd2f76947f42e270da25a/server/README.md)
- EpisodicNode有content、source_description、valid_at，EntityEdge有episodes、valid_at、invalid_at、expired_at，能够表示事件来源与事实有效期；新增episode处理会解析无效事实。这是可追溯/时间纠正的源码结构，未证明抽取推理准确率。[节点](https://github.com/getzep/graphiti/blob/a9ef13f7e2cce23e92abd2f76947f42e270da25a/graphiti_core/nodes.py#L309-L351)、[事实边](https://github.com/getzep/graphiti/blob/a9ef13f7e2cce23e92abd2f76947f42e270da25a/graphiti_core/edges.py#L261-L284)、[插入episode](https://github.com/getzep/graphiti/blob/a9ef13f7e2cce23e92abd2f76947f42e270da25a/graphiti_core/graphiti.py#L1333-L1510)
- remove_episode会删除episode、其创建的边及仅由该episode提到的节点；多episode共享事实及摘要/缓存的删除影响仍须专项测试。图数据库持久化设计有依据，跨重启恢复/迁移未跑。[删除源码](https://github.com/getzep/graphiti/blob/a9ef13f7e2cce23e92abd2f76947f42e270da25a/graphiti_core/graphiti.py#L2164-L2192)
- 本地模型兼容只是配置路径，README也提示小模型结构化JSON可靠性问题。抽取、实体消歧、embedding、重排的模型调用均要计成本；“检索快”不等于“写入免费”。[本地兼容与限制](https://github.com/getzep/graphiti/blob/a9ef13f7e2cce23e92abd2f76947f42e270da25a/README.md)
- Aimy接入推断：高；适合作为时间矛盾/来源实验候选，暂不作为轻量桌面默认依赖。

### 3. MemOS：要区分Python自托管体系和TS本地插件，不能混为一个即插即用SDK

- 根README提供Python API自托管（Neo4j+Qdrant）、云API和本地插件；当前本地插件为2.0.16-beta.1、TS/Node>=20、better-sqlite3等依赖，其现成适配对象是OpenClaw/Hermes/DeepSeek Harness，不是AIRI。packages/memos-core与apps/memos-local-plugin/core并存，本调查已识别v2实际main入口dist/core/index.js，避免拿旧核心源码替v2下结论。[部署路径](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/README.md)、[本地插件包](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/apps/memos-local-plugin/package.json#L1-L105)、[本地插件说明](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/apps/memos-local-plugin/README.md)
- v2本地核心打开磁盘SQLite；traces、episodes、层级归纳与反馈流程存在。traces支持部分内容编辑和删除、删除时同步FTS与episode引用；是否同步失效所有L2/L3归纳、技能、日志、备份，没有运行证明。[SQLite](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/apps/memos-local-plugin/core/storage/connection.ts)、[trace编辑/删除](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/apps/memos-local-plugin/core/storage/repos/traces.ts#L746-L789)、[核心删除入口](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/apps/memos-local-plugin/core/pipeline/memory-core.ts#L3203-L3236)
- 默认embedding为local/all-MiniLM-L6-v2，但llm fallbackToHost=true；默认telemetry开启、llmLog开启且prompt/completion不脱敏。local-first不等于每种配置都零外发，更不等于零模型费用；要核对具体适配器和provider。[默认配置](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/apps/memos-local-plugin/core/config/defaults.ts)
- 根LICENSE是Apache-2.0，本地插件package.json写MIT；本轮未见该子包单独许可证原文件，分发前要厘清具体代码授权范围，不能凭package字段直接断言全部MIT。[根许可证](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/LICENSE)、[包字段](https://github.com/MemTensor/MemOS/blob/a7367d07e55db61099f7b4e2c1108bc5831a24f3/apps/memos-local-plugin/package.json#L1-L105)

### 4. Pipecat：语音打断机制值得学习，中文与动画仍需AIRI侧实测

- Python实时音频/视频pipeline，官方有JS客户端；WebSocket/WebRTC只是传输选项。落入AIRI Vue/Electron意味着新增Python服务/运行包或只借鉴机制，增加音频时钟、取消、连接恢复与事件桥接；不是替换角色界面的理由。[README](https://github.com/pipecat-ai/pipecat/blob/bbb2f6ba47ca61a06b04d6e84ae51fb3ac1436d1/README.md)、[Python项目依赖](https://github.com/pipecat-ai/pipecat/blob/bbb2f6ba47ca61a06b04d6e84ae51fb3ac1436d1/pyproject.toml)
- 默认用户turn start组合VAD和转写，默认stop为LocalSmartTurnAnalyzerV3；输出transport收到InterruptionFrame会取消/重建输出任务或清空可中断音频队列，文本aggregator会将未完回复标为完成=false。源码支持打断和部分回复边界，不代表回顾上下文/动画恢复已经符合Aimy。[默认turn策略](https://github.com/pipecat-ai/pipecat/blob/bbb2f6ba47ca61a06b04d6e84ae51fb3ac1436d1/src/pipecat/turns/user_turn_strategies.py#L28-L80)、[输出取消](https://github.com/pipecat-ai/pipecat/blob/bbb2f6ba47ca61a06b04d6e84ae51fb3ac1436d1/src/pipecat/transports/base_output.py#L602-L626)、[文本未完成标记](https://github.com/pipecat-ai/pipecat/blob/bbb2f6ba47ca61a06b04d6e84ae51fb3ac1436d1/src/pipecat/processors/aggregators/llm_response.py#L53-L81)
- 关键中文风险：示例使用MinWordsUserTurnStartStrategy(min_words=3)，实现用len(frame.text.split())。如果STT返回无空格中文，“等等”“你先停一下”可能都只计一个word，因此不能直接套英文示例。需要中文语义/明确停止词/附和判别的策略，并验证耳机/扬声器回声。[示例](https://github.com/pipecat-ai/pipecat/blob/bbb2f6ba47ca61a06b04d6e84ae51fb3ac1436d1/examples/turn-management/turn-management-interruption-config.py#L83-L93)、[计词实现](https://github.com/pipecat-ai/pipecat/blob/bbb2f6ba47ca61a06b04d6e84ae51fb3ac1436d1/src/pipecat/turns/user_start/min_words_user_turn_start_strategy.py#L97-L121)
- Aimy接入推断：若整个pipeline接入则高；只借鉴turn state/cancel队列机制则较低。语音/STT/TTS/模型提供商成本需按实测时长和token计量，框架BSD许可不代表模型音色与权重同许可。

- Aimy接入推断：服务API适配中等，分发/授权/权限与持续录制策略高。游戏画面中OCR与accessibility只能提供局部文字/界面线索，无法由此证明理解剧情或攻略；还需VLM/音频上下文模型和相关性能实验。
- “每15分钟反馈”最好拆成采集频率、理解频率、主动开口频率三个设置；持续本地事件采集+15分钟汇总可能减少模型调用，但若只15分钟拍一张图会漏掉整个事件。此为工程推断，必须用任务录像/资源测量验证，不是screenpipe现成的伴侣能力。
