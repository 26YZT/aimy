五个反例直接限制“更强”表述：

- DM-C01：已删画像同ref会被挡，但换topic、同来源的同义事实仍可新建。
- DM-C02：故意假模型把“示例叫张三，我本人不叫张三”错误归因为本人姓名，只要source ID有效，原应用层仍接受。验证的是确定性校验边界，不是声称真实模型必定犯错。
- DM-C03：中文非法月日2月31日在原日期函数抛ValueError；不能据纯函数推断完整服务必崩。
- DM-C04：禁用proactive后已有timer仍能claim。原持久消费器不能直接作为正确增强。
- DM-C05：新关联删除会移除父引用，但保留派生正文；源码/UI就是该删除语义，不等于彻底忘记。

因此可以说“候选确实有AIRI主桌面未提供的事实记忆机制，且局部规则已离线验证”；不能说“完整候选比AIRI体验更强”“自动记忆语义正确”“删除不会任何同义复活”“续聊时机自然”。这些需要集成后的真实模型/用户对照；本轮未进行。

## 可复用单位与采用门槛

1. 自动记忆：post_sentinel的用户source标签、持久job、source_ts/revision/epoch与删改拒迟到规则，以及memory_library的管理契约；统一适配AIRI既有来源/存储/leader。原SQLite、FastAPI、双记忆权威不搬入。
2. 有效召回：parse/date/rank/format与生命周期纯规则，先修受控非法日期；AIRI已有工具/上下文runner保留。05:00日界/老化天数/权重和预算只作为待测策略，真实质量不从合成正例外推。
3. 持久续聊：有界决定、持久timer、新交互作废与单领的规则参考；修禁用/失权/在飞结果后，再走AIRI既有assistant-only/语音链。本文没有把额外DND/每日预算说成候选已有。
