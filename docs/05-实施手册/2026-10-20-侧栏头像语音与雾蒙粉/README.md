# 侧栏、头像、语音同步与雾蒙粉

日期：2026-10-20。状态：用户明确要求五项修复；文档先于本轮实现。来源：用户本轮5张截图、当前20261020.2源码与原生反馈。用途：约束增量、分工及验收。MasterGo结构继续使用，主色由用户新指定参考替代。

## 用户可见行为

1. 所有舞台图标在角色窗口右侧同一列；随人物窗口移动，展开也不向四周散列。小高度使用纵向滚动。统一按钮尺寸。
2. 看屏与游戏入口仅保留角色侧栏，聊天去掉这两个入口。共享状态／错误进入侧栏自己的弹窗或popover，不撑宽侧栏。仍使用唯一主Stage采集者。聊天切到历史会话后，从侧栏共享也必须绑定当前聊天，保留账号／角色／会话与TTL检查。
3. 聊天header与角色列表可修改头像；只更新原Card的metadata.avatar。用户选择本地PNG/JPEG/WebP，输入最多2MiB、4096边，本地规范到256px、编码最多256KiB。保存持久data URL，不存blob URL，不上传图片。保存成功才显示新头像，失败保留旧图；移除保留卡片其它字段。角色切换、关闭或再次选图后拒绝迟到结果。暂不扩展.airi分享格式。
4. 角色和聊天都保留语音输入，使用同一主Stage采集／权限owner与可观察状态。两处麦克风主按钮共用开／关连续语音；按钮状态与说明同步。单条语音消息和转文字保留在聊天麦克风菜单，角色端右键／键盘打开语音配置。明确区分总许可、连续聆听、单条语音；菜单中的单条录音不会偷偷启用长期监听。任一端关闭总开关时停止采集、撤销许可、拒绝晚到音频／转写；打开前先等待许可完成。follower不自行getUserMedia，悬停不启动设备。应用重启仍默认关麦。
5. 以用户图片的`#F0E3E8`雾蒙粉底和`#E096AC`柔粉作为基调，文字使用更深的灰玫瑰色以保证可读性。聊天与桌面／设置共用主题方向，移除固定紫色／青色混用。保留主题切换能力；新安装及旧工厂默认主题一次迁移为雾蒙粉，后续用户主动选择的主题不反复覆盖。只更新明确授权的外观设置，不迁移私人聊天、密钥或其它数据。

## 已确认问题

- 侧栏有四象限自动停靠、横向展开、三列菜单；compact共享控件仍内含横排按钮和长错误段落，互相影响测量。
- 聊天录音直接acquire应用麦克风权限，却没有先request；默认off会抛截图中的Capture permission is off or changed。Stage连续听写还有enabled先发布、许可后完成的竞态。旧脚本host测试没有覆盖真实门禁。
- 原卡字段与持久化存在，但上传UI没有。whole-card update会重应用模块，不适合头像；需窄更新与写入失败回滚。
- MasterGo私有紫色token与AIRI青色主题并存；旧全局色相默认220.44，高色度也不符合雾粉要求。

## 写入所有权

- RAIL：controls-island-root、layout/placement、index/账户compact及screen-share-control和测试；不得改语音内部或Messenger。
- AVATAR：原airi-card头像窄提交、图片处理叶子、Messenger头像弹窗与view/window入口及测试；不得改其它角色schema／导出格式／语音／主题store。Messenger内移除共享按钮，保留导航前停止保护。
- VOICE：原speech bus、voice-controls、voice/voice-messages、audio-device、VoiceInputButton、HearingConfig及测试；不得新造采集／会话owner。App或Stage index需要接点时交主代理集成。
- 主代理：跨模块当前会话目标合同、默认主题/配色、App、所有i18n、文档、独立核验与安装。Messenger文件交还前不并行改样式。

## 验收

- 原生窗口点按和真实宽窄渲染：右侧单列、展开不换方向、权限长错误不撑开、小高度可到达全部功能，聊天无看屏/游戏入口。
- 头像：真实图片解码、格式/尺寸/配额错误、只改头像、跨窗口更新、新进程重启恢复、取消/切角色迟到保护。
- 语音：真实consumer初始off、延迟许可、两窗口开关、关麦取消、录音与连续听写不重复发送、同设备单采集源、follower零采集。合成音频验证不等于真实ASR准确性；不读取真实密钥或用前批¥10预算。
- 当前历史会话：侧栏共享只进入该会话；切换停止并改目标，旧帧不能串回。
- 外观：新/旧默认主题、手动换色、重启保持、深浅色与两窗口一致。
- 相关类型、定向测试/lint、完整桌面构建、包字节核对、正确本机签名及隔离原生检查后更新体验包。真实资料保留，旧包备份；不stage/commit/push。
