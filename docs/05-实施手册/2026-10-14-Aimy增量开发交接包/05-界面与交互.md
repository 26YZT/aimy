## 核心流程

自动记忆：用户正常聊天 → 后台候选校验 → 确定性落盘 → 记忆列表更新。无需逐条弹窗确认。聊天中的“记住了”只能在写入回执后出现；提取失败不打断聊天，列表显示“暂未保存，可重试”。

纠正：编辑/说出更正 → 检查来源与当前revision → 保存新版本、作废旧投影 → 当前列表显示新值。冲突时显示“这条记忆已更新，查看新版本”，保留本次输入。

删除：展示范围和已知来源数 → 用户选择 → 先落删除屏障 → 清理与来源删除 → 回执后显示结果。默认只删记忆；未选删来源时聊天仍可查看，但已知来源不得重新抽取此记忆。部分失败说明哪些已生效、哪些待重试；不可显示一个假“全部成功”。

看屏：选择窗口/屏幕 → 系统授权/来源选择 → 就绪 → 开始间隔观察 → 激活状态旁常驻停止。授权中点击停止，则迟到流必须释放。停止只是本次停止，不能写成macOS权限已经撤销；恢复可见不自动开始。

主动：自然聊到相关话题时引用记忆，不需要启动主动定时器。只有另开“轻主动续聊”后才允许无用户输入的本地开口；安静、用户发言、关闭/隐藏、预算耗尽立刻让位，保留沉默作为正常结果。

## 窗口与权限语义

| 动作 | 角色可见 | 用户主动聊天 | 自动采集/主动任务 |
|---|---|---|---|
| 收起聊天面板/关闭独立聊天窗 | 是 | 可重开；已授权语音可继续 | 依用户开关；不改变屏幕/麦克风授权 |
| 安静模式 | 是 | 可以回应用户 | 系统发起文字/语音禁止；看屏需另开，本期建议同时暂停自动推理以省费用 |
| 隐藏主角色/最小化/锁屏/睡眠 | 否/系统状态 | 恢复后可用 | 停采集/旧输出；恢复不自动重开 |
| 退出应用 | 否 | 否 | 撤销订阅、停流/播放器/任务，不留进程 |

AIRI main close→hide仅说明窗口隐藏，不能证明“收起聊天仍看得见角色”。这两个按钮与事件必须分别实机验收。快捷的“停止所有感知”停麦克风与看屏及其在飞结果；不声称撤销macOS系统授权。

## 文案与可访问性

“系统已允许”和“正在聆听/观察”分别展示。费用未知显示调用次数/Token，“尚无费用数据”，不显示虚构金额。记忆来源用人能理解的日期和会话标题，不把内部epoch/job ID写进普通流程。

主要动作一处一个；危险操作有清楚范围与取消；成功不能仅靠颜色。键盘顺序跟阅读顺序，按钮/开关有名称，Escape关闭详情/对话框、焦点返回触发点；正文至少14px，说明至少12px，长中文换行，减少动态受系统设置控制。
