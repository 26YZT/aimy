# VRM 身体动作修复

日期：2026-10-18（Asia/Shanghai）。状态：身体动作入口已实现、验证并安装到体验版。
来源：用户反馈已导入角色，但没有观察到身体动作，以及随附设置页截图。
用途：限定本次动作问题的调查、修复与验收。
风险：文件结构可动不代表运行中的角色已经播放动画。此前说明不作为运行证据。
替代关系：本记录补充当前能力清单的角色验收边界，不覆盖旧验证原件。

## 范围

- 保留 AIRI 的 VRM loader、骨骼、动画与桌面主链。
- 使用用户指定的本地 VRM，只读访问原文件。
- 先复现导入后的身体运动，再修复已证明的绑定或播放问题。
- 核对 Godot 缺资源提示与当前 VRM renderer 的关系，不增加 Godot 运行时。
- 如现有待机已播放，分别说明其微小运动与用户期待的显式身体动作。
- 不调用付费模型，不开启采集，不读取私人 profile、凭据或聊天。
- 不暂存、提交、推送，不改动其他批次文件。

## 技术与文件边界

首选复用 `packages/stage-ui-three/src/composables/vrm/animation.ts` 与 `components/Model/VRMModel.vue`。
如需用户操作入口，再限定到原 VRM 设置组件、原状态同步与中英文文案。
不为此引入新渲染器、外部动作服务或新依赖。
所有运行验收使用独立临时 profile。已安装 App 的替换单独记录备份、包版本与启动结果。

## 验收

1. 用原版本复现，记录加载、骨骼变化、蒙皮变化和画面。
2. 回归测试检查实际动画应用后的骨骼变化。
3. 使用指定资产在桌面 renderer 中观察身体动作。
4. 检查暂停、恢复、模型切换和错误资源的行为。
5. 运行相关工作区类型检查、定向测试及仓库要求的检查。
6. 分别报告源码、自动测试、桌面运行与人工自然度证据。

## 原包复现与本次合同

独立 profile 使用已安装原包，经过文件检查、保存、选中与主舞台显示。
3 秒采样中，左上臂变化约 3.191°，一个受该骨骼影响的蒙皮顶点位移约 0.03596 模型单位。
因此没有复现“待机完全未绑定”。已确认现有待机幅度较小，VRM 设置没有显式身体动作入口。
Godot 缺失的是独立实验舞台资源，本次不依赖它。

补齐内置“挥手”“点头”“停止动作”按钮。点击播放一次，结束返回原待机。
动作复用当前 AnimationMixer 与归一化骨骼。原 VRM 文件与待机文件不变。
动作不写入私人资料，不接付费模型，不宣称任意文字生成动作。
设置窗口复用 Eventa 模型运行通道。命令携带 owner ID 与 model ID，拒绝过期、加载中或错误 renderer。
隐藏或暂停时取消手势。模型切换、卸载时释放动作，不向新模型续播。

## 界面参考锁与决策

采用 Refero 的小改动直接实现流程，以用户截图中的现有 VRM 设置为主参考。
次参考为本工程 MMD 动作面板及 DESIGN.md 的 Button、Container、主题与焦点规则。
采用 Refero motion.md 的明确反馈原则，只给用户主动播放的角色动作增加入口。

| 决策 | 来源 | 保留规则 | 用途 |
| --- | --- | --- | --- |
| 身体动作放在帧率与场景附近 | 用户截图、现有 VRM 设置 | 原容器、字阶和中性色 | 在同一配置页找到动作 |
| 使用有文字的播放按钮 | MMD 动作面板、DESIGN.md | 原 Button、焦点与禁用态 | 明确动作名称与触发结果 |
| 动作结束回到待机，提供停止 | 用户反馈、motion.md | 主动触发与连续过渡 | 让用户观察并控制身体运动 |
| 主舞台确认后显示回执 | 原 Eventa 设置通道 | owner/model 校验 | 不把按钮点击当作已经播放 |

## 实现与验证结果

- `stage-ui-three/composables/vrm/gestures.ts` 在原 AnimationMixer 上叠加一次性的挥手或点头。
- VRMModel 管理动作的取消、完成、暂停和卸载。ThreeScene 与原 Stage 仅转发请求。
- 原模型设置通道新增 VRM 命令，设置窗口使用主舞台确认回执。
- VRM 运行快照使用已加载的 model ID，加载中、暂停或模型身份不符时拒绝命令。
- 原 VRM 设置增加身体动作区，保留注视方向、场景和帧率控件。
- 首次新增动作的桌面验证发现 UUID 与名称分别创建了两个混合绑定，待机覆盖保持姿势。
- 已先用有真实骨骼名称的动态待机测试复现，再统一归一化骨骼名称，修复覆盖。
- 指定 VRM 的包内原生按钮验收：手臂约 90.97°、点头约 16.04°、停止回到待机。

完整命令、包核对与限制见[验证记录](../04-验证记录/2026-10-18-VRM身体动作/README.md)。

## 当前产品边界

本次交付手动挥手、点头和停止。没有接入任意动作生成、动作素材导入或聊天自动选择这些身体动作。
鼠标注视仍使用原 AIRI 实现，默认关闭。用户须在模型注视方向选择“鼠标”。
指定资产的眼球范围约为 10°。输入映射、模式同步和眼骨响应有证据，真实鼠标全屏体验另由用户观察。
