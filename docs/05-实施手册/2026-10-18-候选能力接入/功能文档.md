# 功能文档

日期：2026-10-18。状态：本轮实施合同v1。目的：把保留候选接入AIRI现有产品，增加主动陪伴、语音、互动与资产检查，恢复全产品关注面。默认设置遵循“不启用则原AIRI路径保持”。

| ID | 功能与实际入口 | 用户可观察结果 | 本轮边界/默认 |
|---|---|---|---|
| R2-PRO | 陪伴增强：延后续聊与计划列表 | 对当前会话安排后续关心；关闭/新交互能取消，重启可读计划，不重复领取 | 默认关；一次一个计划；安静时段、次数和冷却；不保证电脑离线后准点提醒 |
| R2-REVIEW | 陪伴增强：回顾已确认记忆 | 从有效来源形成可追溯回顾，日/周/月分组，供用户查看 | 手动为主，闲时可选；不删原文/事实，不把回顾当新用户事实，不复制危险压缩器 |
| R2-TTS | 陪伴增强：朗读语言 | 屏幕/历史保持原文，仅朗读内容译成所选语言 | 默认关；复用聊天Provider；取消不再发TTS，失败提示并保留原朗读；不支持的传输明确提示 |
| R2-DIRECTOR | 陪伴增强：语音表达 | 受支持音色可使用温柔/平静等表达；导演改词或删否定时拒绝 | 不创造第二TTS队列；不支持的Provider保持原语音；不朗读控制标签 |
| R2-ENDPOINT | 陪伴增强：短句收尾 | 可选按说话长度调整静音收尾阈值 | 默认关；保留原VAD/手动输入/打断权威，参数为待体验调优初值 |
| R2-ECHO | 陪伴增强：疑似回声保护 | 最近实际播过的相似文字不自动发送，进入可编辑草稿 | 默认关；不影响手动发送和真实短答，不宣称阻止ASR之前的误打断 |
| R2-ACTIONS | 陪伴增强：Live2D点击与动作间隔 | 按模型的真实点击区域/动作组选择不同反应，减少连续重复和抢动作 | 默认保持原body→tap_body；不存在的组不能播放；其他格式不受影响 |
| R2-FLOW | 陪伴增强：本地组合规则 | 以条件/优先级选择续聊、回顾或保持安静；错误节点和循环不执行 | 只选白名单本地动作，保存恢复，真实事件接线；无任意代码/URL/IM发送 |
| R2-ASSET | 原角色导入：VRM检查与报告 | 损坏/外部引用可见；列出口型/眨眼/情绪/视线/物理能力不足，生成交接报告 | 保留所有AIRI格式；不强制选VRM，不修改资产，不捆绑Kit/donor，不调用远端建模 |

## 共同行为

1. 一个设置入口“陪伴增强”，分为主动、回顾、声音、互动、规则五组，使用AIRI现有组件与导航；角色检查沿用原模型导入入口。
2. 关闭新增功能不产生对应额外模型请求。首次开启说明用途和额外模型费用，不把原¥10验收账本当普通App限额。
3. 新消息、切角色/会话、隐藏/最小化/退出或相关功能关闭，取消新增在飞任务并拒绝晚到提交/播放。
4. 后台主动只能使用已配置的聊天模型、当前会话和有效来源；未经同意不能启动采集或外部操作。
5. 每日额度限制主动续聊轮数；继承的Provider兼容重试可产生额外HTTP请求，不等于人民币费用承诺。语义/声音/动作自然度需后续同条件实测，工程测试不报优胜。
6. 已安装体验App与其私人资料不自动替换/读取。源码增量通过后再单独给出更新结果。
