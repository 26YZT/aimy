## 0. 已知遗留问题（R3 必须复测）

原版评估曾记录以下现象，不能不复核就当作当前缺陷或当前已修。按对应源码/版本与真实运行分别登记：

1. 上次会话自动恢复（新建会话后重启未自动回到该会话；原因推断见实测报告 §4，属待回归确认）。
2. 菜单退出稳定性（最后一次菜单退出及 SIGTERM 后进程残留）。
3. 登录触发的额外云同步：用户已定不额外同步Aimy云端；检查实际config/outbox/WS发送门与恢复路径，不重新询问默认开关。
4. 历史“电脑工具默认开启”不能直接沿用：当前built-in.ts:45–50已defaultActive:false，电脑工具需显式选择；仍要核实际请求的工具白名单，一期不开放电脑自动操作。本轮未运行该测试，不据默认值宣布整机通过。

## 2. 度量口径

### 完整共处旅程补充

游戏/视频陪伴按组合流程观察：打开→选择现有文字/语音→自愿共享示例窗口→对当前情境回应→插话/收起聊天→安静/停止观察→退出与恢复。记录抢话、旧画面、语境断裂、角色等待/说话/被打断状态等现象。各环节可分别标未测；不为补一条验收强行增加首批功能。这是全产品已有目标的检查路线，不是新增第9个记忆对话案例。

文字记忆¥10额度不自动覆盖新的视觉/语音/翻译服务调用。设备授权、模型条件与费用未齐的环节不运行，先留下待验状态。

- 延迟类：从动作完成（说完话/发完图）到首个可感知响应的时间，人工掐表 + 日志时间戳双记录。
- 打断类：停止耗时 = 用户开口到角色声音消失；衔接质量 = 新回答是否引用已说内容。
- 费用类：记录模型、上下文长度、每轮 token，导出账单对照。
- 不用「像真人」这类不可测表述；所有观感按 好/可接受/不可接受 三档记录，附具体现象。
