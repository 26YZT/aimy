## 3. 执行步骤

```bash
# ① 复制来源到本仓（排除运行数据；.env 由 .gitignore 挡住）
rsync -a --exclude '.env' --exclude '.DS_Store' \
  /Users/mima1234/Documents/airi-main/ /Users/mima1234/Documents/aimy/aimy-app/

# ② 首次提交前确认体积与内容合理（预期 ~600MB 工作区，入库内容不含 node_modules）
cd aimy-app

# ③ 冻结安装（沿用 2026-10-10 验证过的命令）
pnpm --filter @proj-airi/stage-tamagotchi... --filter @proj-airi/root install \
  --frozen-lockfile --ignore-scripts --config.confirmModulesPurge=false
pnpm --filter @proj-airi/stage-tamagotchi exec install-electron

# ④ 构建与回归（四项基线）
pnpm -r --filter @proj-airi/stage-tamagotchi... run build
pnpm --filter @proj-airi/stage-tamagotchi typecheck
pnpm --filter @proj-airi/stage-ui exec vitest run --project node \
  src/database/repos/chat-sessions.repo.test.ts src/libs/audio/vad.test.ts \
  src/workers/vad/vad.test.ts src/libs/speech/streaming-session.test.ts \
  src/libs/speech/playback-speaking-state.test.ts \
  src/stores/ai/chat-llm/streaming-control.test.ts
```

体积问题：仓库整体约 600MB（含大量上游文档/资产），是否完整入库由体积实测后定；备选是入库时排除 `docs/`（上游文档）、`bucket/` 等纯内容目录，`LICENSE` 与 `THIRD_PARTY_NOTICES` 必须保留。首次提交单独一个 commit，便于回退。

| 项 | 旧 | 新 |
|---|---|---|
| 产品入口 | `digital-lover` → `@digital-lover/aimy-desktop` | `aimy-app/` → `pnpm --filter @proj-airi/stage-tamagotchi dev` |

## 6. 风险与回退

| 风险 | 缓解 |
|---|---|
| 仓库体积过大 | 提交前实测；必要时排除上游纯内容目录，单独 commit 记录排除范围 |
| 来源目录被改动 | 复制前重算指纹，不符即停 |
