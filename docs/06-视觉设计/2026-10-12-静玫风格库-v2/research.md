## 用户指定 Skill：实际读到了什么

[Lovart「品牌设计系统」](https://www.lovart.art/skills/pnVBXKl81a)，页面作者显示为「麦子今天没灵感」。本轮通过 agent-reach 的 Jina 网页阅读和 ego-browser 读取；Jina 仅获得导航，浏览器成功打开具体详情、简介与两段示例视频，并查看了其中的品牌应用板。

公开介绍表达的流程是：品牌 DNA → 命名与视觉方向 → Logo / VI 规则 → 多个触点的一致应用。这是本轮可学习的公开方法。页面没有显示完整技能指令、可下载 SKILL.md 或内部工作流正文；没有取得完整 Skill，也没有安装或运行 Lovart 的内部技能。未点击“试用此技能”、登录、购买积分或创建外部项目。

本轮的应用是：先定义 Aimy 的产品气质与使用场景，再定义颜色/排版/形状的角色，最后同时验证聊天、权限、连接与设置的表达一致性。**这是对公开方法的转译，不是声称复现了未知的内部流程。**

## 品牌 DNA

对象：在 macOS 上长期相处、游戏和看片时偶尔交流的用户。目标：让角色与交流成为注意力中心，控制界面安静、清楚、可靠。气质：亲近但不幼态；精致来自比例、排版和状态一致性。记忆点：细小的雾玫品牌色，以及聊天中轻量的“双弧”头像标记。

不扩展：社交圈、订阅、电脑代操作、云同步、角色商城、自动长期记忆或移动端产品。正式角色格式/音色、收起窗口语义、记忆保存机制和观察频率保持待答。

## 本轮直接制作目标

用户要求“重新出一版”，因此交付一个完整的参考方向：**Quiet Rose / 静玫**。直接制作依据为：用户已给定的粉色品牌线索 + 本轮指定的成熟度调整 + 可访问的产品/品牌参考；不额外要求用户先选三套方向。

保留：冷白画布、石墨主动作、雾玫选中、系统无衬线字体、紧凑工具条、真实窗口的分组。借用：Raycast 的键盘/工具密度；Linear 的细边界与文字层级。禁止：让辅助参考改变 Aimy 的陪伴产品结构。

媒体策略：界面用原生 HTML/CSS/SVG；小头像为本轮原创的两个相互靠近的弧线（仅识别候选，不代替角色）；原粉雾图标作为现有品牌资产预览。人物模型以有文字的空槽说明，避免把静态装饰冒充 Live2D/VRM。

## 决策账本

| 决策 | 来源 | 角色与边界 | 原因 |
|---|---|---|---|
| 先定义 DNA，再对齐全窗口 | Lovart 公开流程 | 方法，不宣称完整技能执行 | 全 UI 一致比单张漂亮截图更重要 |
| 冷白/石墨为主，玫色少量 | 用户成熟度 + 粉色线索 | action 与 accent 分开 | 减少幼态，保持品牌连续性 |

| 文字为主、面板少而必要 | Refero craft + Linear | 分隔线优先，交互窗才有边界 | 避免商品展示式卡片堆叠 |
| 8 px 控件 / 16 px 窗口圆角 | 参考密度 + macOS 场景 | 角色固定，圆角不一律放大 | 比 v1 更利落的节奏 |
| SF Pro/苹方，15 px 对话 | 系统平台 + craft | 正文不使用装饰性衬线字 | 稳定阅读与中英文一致 |

| 浅色主展示，独立深色预览 | craft + 长时陪伴场景 | 不把“高级”直接等同全黑 | 同时验证日夜使用 |
