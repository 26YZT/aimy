## 这一版的主要变化

| v1 粉雾 | v2 静玫 |
|---|---|
| 粉色主按钮、柔软卡片 | 石墨主动作、玫色身份/选中、分隔线组织 |
| 较大的圆角、展示页布局 | 8 px 控件、16 px 窗口、产品参考工作台 |
| 聊天与部分组件示例 | 聊天、语音、权限、设置、连接、完整状态链 |
| 图标与风格方向 | 变量、组件契约、窗口规则、状态表与前端接入边界 |

原猫耳图标继续作为既有品牌资产展示。双弧标记是更克制的界面头像候选，不表示正式图标替换或人设变化。UI 的成熟感来自比例、密度、状态与一致性，不依靠金色、装饰衬线字体或特效。

## 本地查看

在本目录运行：

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4180/`。直接双击 HTML 也可以看布局，但部分浏览器限制 file 协议的外部 SVG 引用。

不加载外部字体、分析脚本或远程图片。预览对话与字段只在内存中，不保存、不调用模型、不访问设备。模型连接始终是占位地址和只读占位密钥，不能输入真实凭证。
