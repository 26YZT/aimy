# Aimy · 静玫 v2 视觉与前端规范

日期：2026-10-12。状态：独立设计提案，待人工确认，未接入产品。用途：前端和 UI 设计共同参考的可实施规则。来源与风险：[学习记录](research.md)说明 Lovart 仅取得公开简介/示例，完整 Skill 不可见；本规范是本轮转译与设计，不冒称其内部流程。替代关系：v2 候选，不覆盖 v1、产品基线或未决选择。

## 1. 设计方向与适用范围

Quiet Rose / 静玫：在亲近的陪伴产品里建立冷静、清楚的桌面秩序。冷白背景、石墨主操作、雾玫身份与选中。标题和控件不使用装饰衬线字体，页面不铺满粉色、卡片、金色或霓虹。

适用：聊天、语音控制、权限、模型配置、外观设置、对话列表、数据管理、空状态、错误与恢复。正式角色模型/表情/口型/动作是独立领域；风格库用明确的角色空槽，不伪造角色资产或渲染能力。

界面默认浅色，同时完整定义深色。概览中并排出现的深色语音窗用于比较主题，**不表示正式产品需要同时启用两套外观**。产品实施时外观跟随原版主题规则；系统跟随模式与设置持久化需单独接入验证。

|---|---|---|---|

| surface | `#FFFFFF` | `#222026` | 交互面板 |

主操作用 action；品牌/选中用 accent；系统意义用语义色。避免 `primary` 一种颜色包办所有角色。每个区域尽量只有一个主动作。浅底粉字与深色按钮字均独立校验。

正文/辅助文字目标 ≥4.5:1；关键控件、图形 ≥3:1。检查结果见 `evidence/contrast.json`，仅覆盖列出的色对，不构成完整 WCAG/VoiceOver 认证。

## 4. 排版、密度与圆角

字体：SF Pro / 苹方，通过系统字体栈使用；等宽仅用于代码、尺寸或技术字段，不额外下载字体。

| 角色 | 字号 / 字重 | 行高 |
|---|---|---|
| 设计库页面标题 | 36 / 500 | 1.3 |
| 产品页标题 | 24 / 500 | 1.3 |
| 组标题 | 18 / 500 | 1.3 |
| 聊天正文 | 15 / 400 | 1.8 |
| 界面正文 | 14 / 400 | 1.6 |
| 标签 / 按钮 | 13 / 500 | 1.6 |
| 说明 / 提示 | 12 / 400 | 1.6 |

设计库的编号/尺寸标注可能为 10–11 px；正式产品的关键权限、错误和帮助不应跟着缩小。概览缩略窗口中的标注仅为展示，实施时以本表的产品规则为准。中文不做夸张字距；避免标题单字孤行。

基础间距 4，常用 8/12/16/20/24/32/40/48/64。图文 8，控件组 16，内容组 24，完整页面 32–40。不要同时在一组内叠加边框、阴影、彩色底和过大间距。

圆角角色固定：小标签 6、按钮/字段 8、消息气泡 14、窗口 16。状态角标可采用 6，开关可采用胶囊。圆润由角色分配，不一律 24/999。

## 5. 组件与关键状态

机器契约：`component-contracts.json`（13 个组件）。参考 CSS：`components.css`。这些规则框架无关，优先映射到当前已有组件，不另装一套 UI 框架。

| 对象 | 尺寸/状态 | 必须保持的行为 |
|---|---|---|
| 主/次/文字按钮 | 默认高 36，小 30，大 42；8 圆角 | hover、pressed、focus、disabled、loading；同区一个主动作 |
| 危险按钮 | danger / onDanger | 明确对象；删除确认默认焦点在保留动作 |
| 图标按钮 | 36 热区、18 图形 | 桌面小工具最低 32 热区；触屏至少 44；提供可访问名称 |
| 字段 | 高 40、内距 12 | 固定 label；错误关联字段；密钥不能在预览/日志出现 |
| 开关 | 34×21、15 thumb | `role=switch`；文字状态；两项权限独立，默认关闭 |
| 分段与 tabs | 选中/未选中/键盘焦点 | 主题按钮同步；tabs 有完整 ARIA 关系与方向键 |
| 消息 | 15 字号、1.8 行高、最长约 86% | 用户淡底；AI 主要用留白；选择复制；模型内容校验另行实现 |
| 输入区 | 12 圆角；独立工具区 | Enter 发送、Shift+Enter 换行；IME 选字不发送；失败保留草稿 |
| 状态/错误 | 文本+必要图形/语义色 | 重要错误持久显示；不只用 toast 或小色点 |

## 7. 语音状态与权限链

| 状态 | 可见表达 | 用户动作 | 实现边界 |
|---|---|---|---|
| idle | 明确待机、权限关闭 | 文字输入 / 开启权限 | 不显示假采集中 |
| listening | “正在聆听”、小幅音量反馈 | 随时停止 | 需真实麦克风授权；反馈须来自真实输入 |
| thinking | 稳定位置的加载与文字 | 取消 | 不移动已有对话；保留草稿 |
| speaking | 输出状态、显式停止入口 | 插话 / 停止 | 与真实输出同步 |
| interrupted | “已打断”、旧输出停止 | 接续对话 | 停旧音频，拒绝旧结果，不能只换样式 |
| error | 具体错误、检查/重试 | 重试 / 设置 | 不回显密钥、整份请求或截图 |

麦克风与看屏独立授权，默认关闭；开启前解释范围；未授权、请求中、开启和关闭明确区分。关闭、隐藏或退出时的停止与拒绝新调用属于正式实现/验收；浏览器模拟开关不构成证据。

看屏频率仍待答；记忆自动保存/确认后保存仍待答。数据管理应区分聊天、已确认记忆和设置，不能通过视觉卡片宣称已实现长期记忆。

## 8. 动效与可访问性

120 ms 微反馈、160 ms 常规过渡、220 ms 弹层进入。缓动 `cubic-bezier(.2,.8,.2,1)`。不做无限漂浮、装饰呼吸、粒子或控件弹跳。

遵循系统 `prefers-reduced-motion` 与应用设置：关闭持续波形/旋转/位移，并避免平滑滚动；加载仍保留文字。焦点 3 px、offset 3 px；原生按钮/输入优先，不用 div 模拟可点击控件。

需要进一步验证：VoiceOver、系统字体放大、macOS 深浅壁纸、实际窗口缩放、原生授权提示和长对话。当前浏览器有限检查不等于完整平台验证。

## 9. AIRI 前端接入观察与建议

只读来源固定为 `/Users/mima1234/Documents/airi-main`，没有混用工作区旧 `airi-main/`。本轮观察到：

- `packages/stage-ui/src/stores/settings/theme.ts:10` 的主题 store，包含 `themeColorsHue`、`themeColorsHueDynamic`、`applyPrimaryColorFrom`；后者只提取 OKLCH 的 hue。
- `apps/stage-tamagotchi/src/renderer/App.vue:369` 将 hue 写入 `--chromatic-hue`，随后切换 `dynamic-hue` class。

因此，**只把 hue 改成粉色不能实现这套风格**：action/accent 分工、文字/边界/表面、字号、圆角和密度都需要独立语义映射。接入应先在现有主题体系中建立有范围的 alias，再按原组件逐项适配。不要把本库 `:root` 的通用变量整份无审查覆盖进上游，正式 alias 建议增加 `--aimy-*` 命名空间。

示例仅用于交接：

```css
/* Design-to-component mapping; not an applied product patch. */
.primary-action {
  background: var(--action);
  color: var(--on-action);
  border-radius: var(--radius-control);
}
.selected-item {
  color: var(--accent);
  background: var(--accent-soft);
}
```

实施时保留现有 Vue/Chromatic、路由、窗口和会话/音频逻辑。逐项对照原版回归，不复制 `preview.js` 模拟实现，也不从旧独立样机引入平行逻辑。

本轮读取的两个文件 SHA-256：App.vue `cc350e25147e59d63ffa5ef68e9eb2a2929ff97d03cff8e4a6b2db8bf4429550`；theme.ts `f328a0d461dbc9a13df76fbaca109261c9fef474d0558a312975f23b025fff3c`。这些仅固定本轮观察范围，不代替未来迁移版本核验。
