# 参考锁定与设计决策

日期：2026-10-12。状态：本轮设计提案的依据；未冻结产品实现。用途：解释为什么这样设计，并限定后续实现不能随意漂移的部分。替代关系：不替代产品边界、正式角色设定或 R2 任务。

## 简报

为 Aimy 的 macOS 情感陪伴产品设计品牌图标与整套 UI 风格。对象是少量受邀、使用自己模型服务的用户；优先场景是日常对话、游戏及视频陪伴。氛围柔和、亲近、安静，阅读和权限控制清楚。主视觉钩子是粉色猫耳侧脸轻靠衣袖。采用用户提供的明确视觉源，直接制作同一方向的可审阅提案；浅色、夜间、反白为同一标识的资产变体，不是三个竞争产品方向。

## 锁定的视觉目标

主参考：用户提供的柔粉猫耳侧脸。必须保留：圆角雾白底、单色系、侧脸低垂姿态、负形脸部、安静留白。次参考只能负责：Refero 工艺的可读性/一致性与 AIRI 的窗口和控件分工。

媒体策略：重新绘制可编辑 SVG 标记，派生 PNG/ICNS；正式人物区域用明确的品牌占位，不制造假的角色模型；整个 UI 由原生 HTML/CSS 展示，无外部图片和字体。

拒绝：描摹原图角色、强行确定正式猫娘人设、渐变霓虹、玻璃效果满屏、每个控件都加爱心、粉字粉底、将桌面角色与聊天/设置改成管理后台、用品牌粉代替危险红、在关闭感知时仍显示“正在陪你看”。

## 决策表

| 决策 | 来源 | 采用规则/角色 | 理由 |
|---|---|---|---|
| 猫耳侧脸与靠袖姿态 | 用户参考 | 仅品牌标识，不决定正式角色外观 | 延续用户认可的情绪线索 |
| 重绘粗轮廓与负形脸 | 用户参考 + icons 工艺 | SVG 母版；小尺寸减少细节 | 避免低清原图放大及小尺寸糊线 |
| 雾白和浅粉 | 用户参考 + color 工艺 | 雾白为画布，浅粉为选中/用户气泡 | 大多数区域保持安静 |
| 莓粉 `#B44870` | color 工艺 + 用户粉色方向 | 主要操作；浅底深粉文字 | 原图浅粉不适合承载按钮白字 |
| 梅灰正文与辅助文字 | color 工艺 | 4.5:1 以上的关键文字色对 | 保留柔和感并可长时间阅读 |
| 深梅灰夜间底 | color 工艺 + 粉色家族 | 独立深色变量，浅粉操作色 | 不机械反相、不额外引入紫色强调 |
| SF Pro / 苹方 | macOS 优先 + typography 工艺 | 系统字体，不下载字体 | 贴合桌面产品，也保持离线能力 |
| 12 px 控件、18 px 气泡、24 px 面板 | 用户圆润参考 + craft | 各组件角色固定 | 圆润但不全用胶囊形 |
| 24 网格、1.8 线宽功能图标 | icons 工艺 | 统一 currentColor 与圆头 | 图标像同一套文字一样一致 |
| 独立角色、聊天、设置 | AIRI 现有截图 + 当前产品方向 | 继承窗口分工，不迁入旧样机 | 视觉提案不改变主线工程 |
| 独立权限开关与具体状态文字 | 当前产品底线 | 默认关闭，关闭即时反映 | 不让装饰或拟人化文案掩盖感知状态 |
| 记忆卡注明后续提案 | 当前待答事项 | 仅定义来源/纠正/删除样式 | 不擅自选自动保存机制 |
| 120–260 ms、支持减少动态 | craft + 陪伴场景 | 界面轻过渡；无装饰呼吸动画 | 避免打扰游戏、观看和长时间使用 |
