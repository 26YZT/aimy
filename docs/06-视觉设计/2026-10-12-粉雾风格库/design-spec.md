# Aimy · 粉雾视觉规范 v0.1

日期：2026-10-12。状态：可评审提案，人工最终确认待完成；未接入主工程。用途：品牌素材与全 UI 风格的设计/实现交接。来源：[参考锁定](research.md)、用户本轮附件、当前项目边界与 AIRI 原版界面证据。风险：图标导出和原型验收不代表可发布产品；权益、原生安装及真正功能验收仍独立进行。替代关系：不替代 R1–R4、正式角色设定或产品待答选择。

## 1. 品牌目标

“轻轻靠近，刚好陪着你。”视觉呈现亲近、安静、可长时间相处的感觉。品牌的主要记忆点是猫耳侧脸与靠袖动作；界面以清楚和分寸为先，不把所有地方装饰成人设周边。

图标是品牌符号，**不要求正式角色必须是猫耳、粉色头发、少女或使用某种模型格式**。正式人设、角色格式与音色仍另定。角色模型、表情、动作和口型并未在这个包中制作。

## 2. 标识与应用图标

### 主版本与变体

- 主图标：雾白底、浅粉发部、较深粉的前发与衣袖轮廓。默认用于应用列表、Dock、启动台、下载页。
- 夜雾版：深梅灰底、樱粉前景。作为可选品牌资产，不因用户切换界面主题就改 Dock 图标。
- 莓粉版：高识别的反白表达，用于品牌头像或活动素材；不在每个界面重复出现。
- 无底标记：透明底，用于头像、品牌位或空状态，附近无需再塞爱心或猫爪。
- 小尺寸：16–32 px 删除内耳/发丝/衣袖细节，保留猫耳、侧脸和靠袖外轮廓。
- 菜单栏：独立的单色负形标记，保持透明背景。使用系统 template 语义，由 macOS 根据背景着色；不可把多色大图简单变黑当菜单栏图标。

### 母版与导出

SVG 母版使用 512×512 viewBox，标称 1024×1024。应用底板在 viewBox 中为 x=48、y=48、宽高=416、圆角=96；对应 1024 文件的外缘约 96 px 留白和 832 px 底板。外部区域透明，不画外部投影，避免系统阴影叠加。

图标路径保留可编辑性；界面头像可使用无底标记。图形外保持不少于约 1/8 标记宽度的净空，不叠加文字、角标、通知点或界面状态。非等比拉伸、旋转、描边加粗和发光效果都不属于本规范。

`Aimy.iconset` 标准项：`icon_16x16.png`、`icon_16x16@2x.png`、`icon_32x32.png`、`icon_32x32@2x.png`、`icon_128x128.png`、`icon_128x128@2x.png`、`icon_256x256.png`、`icon_256x256@2x.png`、`icon_512x512.png`、`icon_512x512@2x.png`。16/32 实际像素采用简化母版，其余采用完整母版。

PNG/ICNS 已按这些规格准备。macOS 原生 Dock/菜单栏的光学大小、圆角、亮暗壁纸表现与模板接入仍需安装后的实机验证。

## 3. 色彩与角色

原始阶梯：Rose 50 `#FFF3F7` → 100 `#FBE6EF` → 200 `#F2CADB` → 300 `#EDBED0` → 400 `#D78BA9` → 500 `#CE7094` → 600 `#B44870` → 700 `#9B3A60` → 800 `#81304F` → 900 `#562238`。

组件读取语义色，不直接绑原始色。插画可以使用 300/500，承载操作和文字则使用通过对比度检查的语义色对。粉色不得承担错误或删除的意义。

| 语义变量 | 浅色 | 深色 | 角色 |
|---|---|---|---|
| canvas | `#FCF9FA` | `#211C23` | 窗口/页面背景 |
| surface | `#FFFFFF` | `#2A242D` | 内容面板 |
| surfaceSoft | `#F6F1F4` | `#332B35` | AI 气泡、低强调区 |
| surfaceRaised | `#FFFFFF` | `#3B303C` | 弹层与浮动菜单 |
| text | `#372F36` | `#F8EDF3` | 正文、标题 |
| textSecondary | `#73646E` | `#C5B2BF` | 说明、时间、图标 |
| textMuted | `#7E6D78` | `#B7A1B0` | 占位、低强调文字 |
| border | `#E7DDE3` | `#4C3C49` | 装饰分隔，不单独表示关键控件边界 |
| controlBorder | `#9B8994` | `#9B8293` | 输入、次按钮与关闭开关的可见边界 |
| primary | `#B44870` | `#F1A9C5` | 主要操作、选中指示 |
| primaryHover | `#9B3A60` | `#F7C1D6` | 主操作悬停 |
| primaryPressed | `#81304F` | `#E28BAF` | 主操作按下 |
| onPrimary | `#FFFFFF` | `#34212D` | 主操作上的内容 |
| primarySoft | `#FBE6EF` | `#49303D` | 低强调选中/用户气泡 |
| primaryText | `#9B3A60` | `#F3B9CF` | 浅强调底上的文字 |
| focus | `#9B3A60` | `#F1A9C5` | 键盘焦点环 |
| success / successSoft | `#326C59` / `#EAF4EF` | `#A2D6BE` / `#233C32` | 已确认成功 |
| warning / warningSoft | `#865C21` / `#FFF3DC` | `#E8C082` / `#423524` | 未授权、需要注意 |
| danger / dangerSoft | `#B13E4C` / `#FDECEF` | `#FFA7B6` / `#472B35` | 错误、危险动作 |

中性色占大多数界面，品牌强调只出现在主要动作、选中和相关信息上。浅深主题都禁用跨组件彩色渐变与粉色光晕；品牌图像可以保留双色，但不增加不必要的第三强调色。

对比度检查范围详见 `evidence/contrast.json`：正文 ≥4.5:1，主要控件边界/图形 ≥3:1。浅色主按钮白字约 5.12:1，浅色辅助文字对面板约 5.56:1，深色主按钮内容约 8.01:1。该检查是指定色对验证，不构成全产品可访问性认证。

## 4. 字体与排版

系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`。中文优先苹方，英文跟随系统；不下载字体、不在产品中嵌入未授权字体。技术字段及尺寸用系统等宽字体，日常界面不使用等宽体。

| 角色 | 字号 | 字重 | 行高 |
|---|---:|---:|---:|
| 设计展示标题（非产品正文） | 48（响应式 32–50） | 600 | 1.3 |
| 页面标题 | 28 | 600 | 1.3 |
| 组标题 | 20 | 500/600 | 1.3 |
| 聊天消息 | 15 | 400 | 1.8 |
| 正文/设置项 | 14 | 400/500 | 1.6 |
| 标签/按钮/说明 | 13 | 400/600 | 1.6 |
| 辅助提示 | 12 | 400 | 1.6 |

展示画廊的尺寸标注/日期可能用 10–11 px；产品中的重要权限、错误和操作说明不应因此缩到 10 px。避免全角中英间距不一致、标题断成单字孤行。较长地址允许换行/横向滚动；不要通过缩小字体隐藏长内容。

## 5. 空间、圆角、深度与动效

- 4 px 基础网格；常用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64。
- 控件内部图文间隔 8，消息与内容间距 12–16，组间距 24，页面间距 32–40。
- 小标签/小菜单圆角 8，按钮/输入 12，消息气泡 18，主面板 24；胶囊形只用于状态/分段/开关。
- 输入/主按钮默认 40–44 px 高，触屏可点区域至少 44 px；桌面图标按钮热区至少 32 px，默认 40 px。
- 浅色面板轻投影：`0 16px 48px #52344712, 0 2px 6px #52344706`。深色优先通过稍亮表面与边界区分层级。
- 状态过渡 120–180 ms，弹层最多 260 ms；缓动 `cubic-bezier(.2,.8,.2,1)`。按下最多 1 px 位移，不做弹跳。
- 尊重 `prefers-reduced-motion` 与应用“减少动态效果”。长时间陪伴界面不做无限浮动、呼吸灯、粒子或闪烁。唯一持续动态是有明确工作的加载指示。

## 6. 组件契约

| 组件 | 默认与状态 | 内容/交互要求 |
|---|---|---|
| 主按钮 | primary → hover → pressed；不可用独立 disabled | 同一区域一个主要动作；图标可选、标签明确 |
| 次按钮/文字按钮 | controlBorder / transparent | 不竞争主动作；键盘焦点可见 |
| 危险操作 | danger 前景 + dangerSoft 底 | 具体写明删除对象；确认弹窗保留取消动作 |
| 输入框 | surface 底、controlBorder 边；错误 danger 边 | 固定可见 label；占位不替代标签；说明/错误关联字段 |
| 开关 | 独立控制边界 + 文本状态 | `role=switch`/`aria-checked`，关闭默认态不能靠颜色单独传达 |
| 状态 | 图标/文字/必要色 | 不只用红绿小点；无权限、权限关闭、开启、系统拒绝需区分 |
| 聊天气泡 | AI=surfaceSoft，用户=primarySoft | 最大 85% 左右内容宽；不同角部轻变化；正文可选择复制 |
| 加载 | 行内 spinner + 动作文字 | 不阻塞整窗；失败后可重试；取消后拒绝旧结果属于实现验收 |
| 空状态 | 小标记/功能图标 + 一句说明 + 可选动作 | 不伪造已有数据，不用大插画挤占对话 |
| 弹窗 | surfaceRaised、清楚标题、底部动作 | Escape/取消、焦点回归、非必要不强迫确认 |
| Toast | 短暂操作反馈 | 关键错误和权限阻塞需保留在相应区域，不能只闪过 |
| 菜单/分段 | surfaceRaised / surfaceSoft | 选中可辨、键盘可达、颜色意义和按钮一致 |

键盘：输入 Enter 发送、Shift+Enter 换行；拼音输入法选字时不发送。标签页左右键/Home/End 切换；焦点环 3 px + 3 px offset。图标按钮提供可访问名称。正式接入必须验证 VoiceOver、焦点顺序和系统放大；本轮仅完成浏览器有限键盘检查。

## 7. 全界面应用映射

| 界面 | 风格应用 | 不能由设计稿推定的产品行为 |
|---|---|---|
| 应用图标/启动/关于 | 主图标、名称、系统字体、保留上游署名 | 不改内部协议、包名或数据命名空间 |
| 初次配置/模型连接 | 少量步骤、固定 label、清楚连接/错误状态 | 不在静态前端嵌密钥，不以假连接显示真实成功 |
| 透明桌面角色 | 沿用角色独立窗口；控制条采用雾白/深色轻面板 | 角色格式和正式模型不由 logo 决定 |
| 聊天窗口 | 15 px 消息、柔色气泡、底部输入、独立权限提示 | 隐藏/最小化与收起聊天语义继续待答 |
| 设置页 | 保留 AIRI 导航和分组；本规范映射 tokens | 不重新搭 UI 框架、不合并成管理后台 |
| 语音设置/进行中 | 麦克风关闭/等待/聆听/思考/说话/已打断分开表达 | 插话停止旧声音和陈旧结果要靠真实运行验证 |
| 看屏授权/进行中 | 范围可见、状态文字、可立即关闭 | 默认关闭；授权范围/采集频率另按产品决定 |
| 会话与记录 | 中性列表、当前项浅粉、明确删除/恢复状态 | 写入与重启恢复需单独证据 |
| 已确认记忆（后续） | 来源、纠正、删除；重点内容阅读清楚 | 自动保存/先确认仍待答，不在原型中实现 |
| 错误与离线 | 保留用户草稿；具体原因 + 可恢复动作 | 不把供应商错误、设备权限、网络失败混成一种情绪回应 |

聊天与桌面角色的独立窗口结构来自现有 AIRI，而非旧独立样机。画廊中的模型连接 tab 用于并排审阅组件，并不授权将正式 AIRI 页面导航改成三个 tab。

权限状态矩阵：`关闭`（中性，直接可见）、`请求前说明`（明确范围）、`系统未授权`（warning + 系统设置入口）、`开启中`（明确文字 + 立即关闭）、`已停止`（中性）。本轮预览只演示关闭/说明/开启/关闭视觉；不弹系统授权、不访问设备。隐藏或退出即停采集是未来实现验收条件，预览不构成证据。

## 8. 文案与拟人化边界

对话可以温柔：“我陪你待一会儿，好不好？”设置和权限必须具体：“开启后，才开始听你说话”“看屏已关闭”“这次没有连接上”。不使用情感施压、占有欲或内疚文案诱导授权，不用“永远记住你”承诺未实现的记忆能力。

敏感错误不回显密钥、整份请求或原始截图。危机/未成年人兜底按照既有产品底线处理，不由视觉提案削弱，也不把情绪识别包装为医疗判断。

## 9. 后续接入与发布闸门

本轮只在 `docs/06-视觉设计/` 增加独立产物，并为根文档中心增加入口。没有创建运行时、引入依赖、改产品启动或实施迁移。`gallery.css` 仅为说明页布局，`preview.js` 仅为演示，二者不得整页搬入产品。

后续接入先以获确认的图标/语义变量为目标，按 AIRI 原有 Chromatic/组件体系映射；保留原页面、窗口、交互和内部标识。需单独形成有界实施任务与回归证据，本次设计请求不等于获准执行 R1/R2。

正式发布前仍需：

1. 人工确认主图标、色彩、浅深主题和猫耳作为品牌符号是否长期使用。
2. 确认 Aimy 名称及标识权益、参考图来源；本轮未取得授权或商标检索结论。
3. macOS 包安装后的 Dock/启动台/菜单栏检查、透明度和 Retina 检查；本轮 ICNS 编码成功仅证明文件可导出。
4. 实际 AIRI 组件的主题映射、键盘/VoiceOver/放大/减少动效与原版行为回归。
5. 麦克风、看屏、密钥、取消、持久化与删除按正式功能验收；设计原型没有这些能力。
