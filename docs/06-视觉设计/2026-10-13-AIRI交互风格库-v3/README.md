## 这版可以体验什么

1. 打开历史会话，带着文字草稿和图片来回切换。
2. 添加本地图片，查看读取、就绪、移除和错误状态；图片不会上传。
3. 在“消息发送失败”场景重试，草稿和附件保留。
4. 区分“语音陪伴”和“录一条语音”，两者都经过麦克风授权的模拟状态。
5. 区分“系统已授权”和“正在采集”，选择看屏来源、停止分享或停止所有感知。
6. 取消示例回复，阻止延迟的旧示例结果重新出现。
7. 测试模型配置样式，切换服务后清除旧结果，选择模型后才显示就绪。

所有消息、设备、授权、连接和音频状态均为模拟。没有真实模型调用、系统授权、录音、截图采集、电脑操作或持久化。浏览器刷新会清空演示数据。

## 给前端的文件

| 文件 | 用途 |
|---|---|
| `tokens.json` | 本目录规范变量的机器读取源 |
| `tokens.ts / tokens.css` | 从同一 JSON 派生的类型与 CSS 变量 |
| `components.css` | 按钮、字段、开关、状态等参考样式 |
| `interaction-contracts.json` | 会话、附件、权限、语音、取消与模型配置的状态契约 |
| `DESIGN.md` | 布局、组件、交互、来源与接入边界 |
| `assets/` | 新图标位图与 28 个 SVG 功能图标的 sprite |
| `index.html / preview.css / preview.js` | 独立参考界面与模拟逻辑，不能当作新的产品运行时 |
| `build-assets.py` | 从本地变量与母版重新导出；PNG 尺寸转换需要 Pillow |
