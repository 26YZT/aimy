# Aimy v3 · 界面与交互规范

日期：2026-10-13。状态：设计提案，待人工确认；适用范围仅本目录。用途：UI / 前端接入参考。来源：用户固定的猫耳侧脸、[Impeccable 学习记录](impeccable-study.md)、[AIRI 源码映射](airi-ux-map.md)。替代关系：新增 v3；保留 v1/v2，不覆盖主工程、正式角色或未答产品决定。风险：模拟交互和静态图像不能代替真实产品能力或上线验收。

## 方向与模式

产品屏幕采用 Impeccable 的 Operate 模式，风格库说明采用 Read 模式。用户优先任务是陪伴、文字交流、图片分享、语音与独立授权看屏。导航和控件沿熟悉的桌面习惯，品牌进入色彩、字体、密度与猫耳头像。

这一版的辨识细节是“猫耳侧脸身份 + 可持续观察的感知状态”。不再使用 v2 双弧头像；不为高级感增加装饰字体、编号眉题、卡片网格、霓虹或全页进场动画。

固定方向：猫耳、人类侧脸、柔粉、白底。图标重构的是重心、负空间、鼻部与发部比例，不改变为抽象字母或另一种吉祥物。正式角色模型、格式、人格和音色不由图标决定。

## 图标与素材

新版使用内置 image generation 工具，从原参考重新构图并定向清理。最终是白底 RGB 位图母版，输出大小为 1254 px，派生 1024 / 512 / 256 / 128 / 64 / 32 px。缩放只用于导出，不进行手工换脸、描摹或去背。

面部与耳尖为第一辨识，发部形成完整外轮廓，底部衣袖为次要形状。头像/窗口标识使用 24–48 px；较大品牌位可使用 128–512 px。采用统一圆角容器，保持等比；不叠文字、徽章、星星或新纹理。

母版不是可编辑 SVG，也没有声称严格只有两个像素色值。正式 16 px 光学简化、透明 macOS 图标包装、菜单栏模板和 Dock 实机检查未完成。参考角色截图只解释 AIRI 布局，不是新 Aimy 角色或可直接发布素材。

玫粉负责主要动作、选中与身份。成功、提醒、错误采用独立语义色。弱分隔线不承担输入框可见性；关键边界使用 controlBorder。正文/占位至少 4.5:1，关键控件和焦点至少 3:1。32 个关键色对检查只是有限证据，不等于整体可访问性认证。

聊天和设置窗口通过柔和阴影表达独立层级，避免边框与厚重阴影双重包裹。工具浮条只有轻微立体感，内容区保持清楚。背景的第二中性色层支持桌面/窗口的分工。

## 字体、间距与控件

产品使用系统 SF Pro / 苹方。Operate 模式允许熟悉的系统字体，不机械套用品牌展示页的字体禁令。UI 标题 23–26 px、组标题 19 px、消息默认 15 px（大字 17 px）、正文 14 px、标签 13 px、说明 12 px。消息行高 1.8，说明 1.6–1.8。

设计库的来源/尺寸标注与缩略窗口辅助信息会小于 12 px；正式产品关键授权、错误和操作文本以产品字号规则为准，不照搬缩略图大小。长文本允许换行，不缩小字号掩盖溢出。

4 px 基础间距：8 图文，12 控件内距，16 内容组，24 窗口内容，32–40 大组分隔。按钮高 40 px、输入高 42 px、工具岛 44 px；控制圆角 12、气泡 16、窗口 20。原生浮窗的圆角最终跟随 AIRI / macOS 容器校验。

功能图标 24 网格，常用 18–20 px，1.8 px 圆头描边。图标按钮有可访问名称和可见焦点；触屏场景增加热区。浏览器使用原生滚动/选择控件，只为选中文字、光标和焦点设语义色，不另造滚动条。

## 交互契约

### 会话与草稿

- 历史按钮与可点击标题同时可进入抽屉；显式关闭和 Escape 可返回。
- 文字、附件与已录片段按会话保留；切换时不清空当前草稿。
- 切换会话先结束当前录制，保留片段；当前回复的延迟结果不能进入另一个会话。
- 这些只在本页内存中演示。产品必须独立提供保存、重启恢复、纠正和删除证据。

### 附件与发送

- 附件状态：读取中 → 就绪，或读取失败；可移除，多个附件横向排列。
- 失败就近提示并保留文字；读取完成不表示模型已经理解图片。
- 本预览支持 PNG/JPG/WebP/GIF，单文件 10 MB 限制仅为演示保护；正式限制沿原产品配置另行确认。
- 空内容不能发送，读取中/录制中禁发。Enter 发送、Shift+Enter 换行，中文组合输入未完成时不发送。
- 发送失败保留草稿、片段和图片，“重新发送”就在失败区域。

### 连续语音、单条录音与全停

- “语音陪伴”从角色控制岛进入；“录一条语音”在聊天输入栏，两种任务不混淆。
- 两者均受同一麦克风授权状态约束；未授权/拒绝时不得进入录制。
- `auth = unknown / granted / denied` 与 `capture = idle / listening / recording` 分开表达。
- 单条录音开始时暂停连续聆听；切回连续陪伴先结束当前片段并保留草稿。本规则是本轮设计提案，接入需验证共用音频管线。
- 停止所有感知同时结束持续聆听、单条录音和看屏；已经录下的示例片段保留待发送，授权状态不会被伪称为系统撤销。
- 浏览器页面不可见时，本预览停止所有模拟采集与旧示例回复；这不证明原生隐藏/退出实现正确。

### 看屏

- 在按钮旁展开来源、授权与状态，避免每次都跳设置页。
- 来源明确为用户选择的窗口或屏幕；分享期间显示来源与停止动作。
- 拒绝后说明恢复方法，重新尝试是独立动作；停止不自动开启其他感知。
- 示范来源是静态示例，不访问系统录屏，不调用电脑操作。采样频率仍待答。

### 输出与取消

- 发送位置保持稳定，思考/说话有单独取消/打断动作。
- 取消或会话切换递增请求代号；旧定时示例结果无法回填。
- 真实实现还需停止旧 TTS/模型流、检查 generation/session IDs、拒绝陈旧回调。不能只换 UI 状态就报告打断完成。

### 模型设置

- 区分已填写、检查中、连接通过、待选模型与模型就绪。
- 失败说明下一步并保留输入；服务变更清空旧结果。
- 每次检查绑定配置与请求代号；旧服务的迟到结果不会落到新服务。
- 连接通过后明确选择模型，再显示就绪。预览地址/密钥只读，不接收真实凭证；所有连接反馈均为示例。

## 渐进披露与动效

权限控制使用可轻关闭的原生 popover，逃离窗口裁切区域；位置限制在视口内。只有真正需要保护焦点的操作才使用阻断对话框。停止入口常驻于激活状态附近，不藏进菜单。

状态变化 150–220 ms；无全页进场表演、装饰波形或虚构进度。遵循系统及应用的减少动态设置。提示文字保持即时可读，视觉样式不能替代设备/网络真实状态。

## 前端接入与验收边界

按原 AIRI 的 Vue / Chromatic 主题与组件边界映射语义 token。不要把本风格库的整页 HTML、模拟 JS 或示例数据复制成平行运行时；不要为改品牌重命名内部包、IPC、存储命名空间。

建议按角色控制岛、聊天标题栏/会话抽屉、编辑器状态、权限/语音、设置反馈逐块适配；每块保留原功能回归证据。`interaction-contracts.json` 是设计验收输入，不是实现已经完成的证明。

继续待答：收起聊天与隐藏/最小化的语义、记忆自动保存/先确认、观察频率、正式角色与音色。真实模型/设备、VoiceOver、原生窗口行为、长期记忆/重启恢复、安装包与正式资产发布均未验收。
