## 本轮接口收口

以下均是现有Pinia/IPC及本地存储逻辑接口，不是新增HTTP服务。路径以`aimy-app/`为根。

| 逻辑合同 | 真实实现 | 重要边界 |
|---|---|---|
| 资料读取 | `packages/stage-ui/src/stores/memory.ts` 的`readProfile` | 返回已保存的归一字段与来源，不能用当前事实猜回最初填写内容 |
| 当前/历史列表 | 同文件`listMemory`，DTO在`types/memory.ts` | 固定50条分页，游标校scope/filter/revision；版本变化拒绝旧游标 |
| 原话与血缘 | 同文件`readSourceSnapshot` | 精确来源版本，available/missing/changed/deleted；读盘失败不冒充来源缺失；旧`readSource`兼容 |
| 写回执与重试 | `submitProfile/setEnabled/setModelPolicy/getOperation`及`database/repos/memory.repo.ts` | 操作结果元数据与交易一起保存；同ID重试返回原结果；旧回执未记结果就明确未记录 |
| 关于我操作 | `components/scenarios/settings/about-me.vue` | 原UI保留；失败后复用操作ID和观测版本，显式刷新或重新选择才换操作 |
| 诊断汇总 | `services/memory-acceptance-diagnostics.ts` | 独立快照，限定数量与字段；未配置、失败和真实零值分开；跨scope拒绝 |
| 服务商与费用 | `services/acceptance-generation.ts`、`stores/ai/chat-llm/llm.ts`、记忆worker | 用户自定义实例先通过registry解析定义，避免把实例名称当服务商；原共享账本保留 |
| 发送边界 | `packages/core-agent/src/runtime/request-guard.ts` | 实际发送固定`redirect:error`，避免自动跳转绕开目标核验 |
| 时间接点 | `services/conversation-clock.ts`、聊天factory与记忆整理/召回 | 普通产品仍用真实Date/Intl；仅受控副本替换函数，不改系统时间或持久化/租约时钟 |

## 离线工具

`apps/stage-tamagotchi/scripts/acceptance/`：

- `dataset.ts`严格校验8例原文来源、18输入与时钟/会话切换，丢弃评分侧字段。
- `prepare-build.ts`使用独立COW副本；Node在macOS不支持强制COW时调用系统`clonefile(2)`，不退成普通复制/硬链接；精确记录共同clock和单文件driver适配。构建直接运行已安装bin，不执行包管理器。
- `airi-baseline-adapter.ts`、`baseline-transport.ts`、`baseline-renderer-fetch.ts`保留原SDK请求构成与流式正文，费用门禁在最后发送前；host持有授权，renderer仅拿有界响应。Aimy不重复套第二次门禁。
- `driver-common.ts/driver-airi.ts/driver-aimy.ts`只注入临时构建，通过真实store和IndexedDB运行；恢复模式只检查已有配置，不补建。
- `offline-host.ts/offline-network.ts`在测试进程内生成合成凭据，只许可任务的本机端口；保留Electron原生沙箱；Node HTTP的null path按TCP语义处理。
- `offline-build.ts/offline-runner.ts`串接准备、隔离profile、逐case运行、新PID恢复、新空会话、产物校验、每进程请求/账本核对、合成key不泄露检查与退出清理。没有付费模式开关。

本轮通过的实际运行输入与源码/产物SHA见机器证据。适配器与门禁可供后续真实runner使用，但离线runner本身不能当作真实模型批跑已经就绪。
