# Aimy 全产品方向：第一性原理审阅

日期：2026-10-15，Asia/Shanghai。状态：审阅与文档纠偏交付；未改产品、未开工。任务：用户要求切换开发模型后重新了解整个产品、复用项目、docs/PRD，判断方向或注意力是否偏移。范围：当前决定/全局与首批PRD、五项目裁决/关键源码、阶段任务/验收及已有证据；不刷新上游、不做市场排名或真实模型/设备调用。

## 判断

**根方向正确；注意力确实收窄到了文字记忆和它的工程细节，存在让局部批次取代整个产品的风险。** 尚未进入新增代码实施，因此这是方向与交付风险，不是已发生的产品失败。

Aimy要解决的是：电脑前的日常、游戏、视频里，有一个自然可交流、理解获准情境、能延续相处、可控可信的伴侣。记忆是连续性的必要支撑；只把数据存准，不能保证她好聊、声音自然、人物有回应或陪看时不抢话。

保留用户亲自选择的记忆首批、AIRI唯一底座和现有8例；恢复[全产品总纲与体验地图](../../00-当前方向/产品总纲与当前路线.md)，并把原有基线体验、中间验证、完整首批验收分开。没有必要重建AIRI、把所有候选都装进产品，或再增加一轮无限文档设计。
