# 验证与AI评测计划

日期：2026-10-14。状态：验证方案交付；新能力未实施，真实模型/设备/用户验收未运行。来源：PRD、源码/隔离失败、已有R3与130项AIRI定向测试。用途：分批验收和体验迭代，不用测试数量代替产品结论。风险：以下建议量表/阈值未做试标校准。

## 1. 四类证据分别记录

| 层级 | 证明什么 | 不能证明什么 |
|---|---|---|
| 源码/全树清点 | 文件、接线、依赖、实现/占位与阅读覆盖 | 安装可跑、模型质量、用户喜欢 |
| 离线工程 | 状态、来源、删除/取消/恢复/预算等可重放规则 | 真实模型、硬件静音、自然陪伴 |
| 真实模型/设备 | 指定版本/设备/网络下的输出、延迟、费用、语音/看屏 | 所有模型/所有用户/所有版本 |
| 用户体验 | 本人觉得合适/自然/打扰的具体场景 | 确定性删除/权限正确性的替代证据 |

已经完成的是相应源码和离线范围。130项原AIRI测试、37条前轮候选隔离观察和本轮补充检查各自保留输入/版本/局限，不合成一个“产品总通过率”。缺陷成功复现也不叫功能通过。

## 3. AI系统质量实验设计

对象是**AIRI+Aimy增量系统**，不只一个模型。先冻结基线commit、Prompt/角色卡hash、数据快照、模型精确版本/参数、召回/过滤、工具与设备；一次只改一个主要因素。AIRI原版不具备的长期事实能力，比较“缺口是否补齐”，不伪装成对称模型排名。

建议切片：明确称呼/偏好，否定/引用/假设，更正/过期，跨会话/重启，删除/同义来源，相关主动回忆/无关沉默，画面新鲜度/错误与注入，中文停顿/附和/回声，角色语气/不同意见/关系边界。先做少量真实试跑诊断，再按正式模型评测目标确认覆盖矩阵，未确认前不生成已冻结cases.csv。

建议量度（待目标卡/试标确认，不冒充已达标）：

- 事实精确率 = 有足够本人来源且当前有效的已保存事实数 / 所有已裁定保存事实数；另报未裁定、拒写和漏记，不能靠全部不写刷高。
- 召回覆盖 = 在本场景允许/应该用的有效事实中被正确检出的数量 / 人工标注的应召回数量；固定信息与经历分层，来源错误单列。
- 主动提起合适率 = 有依据、相关、时机不打扰的主动提起 / 所有已裁定主动提起；再报应提未提与不该提而沉默，不能只统计说得好的。
- 人格/中文自然度由用户按“好/可接受/不可接受+具体现象”评，必要时GSB盲化同条件比较；未经校验的AI Judge不能替代真人喜好或高风险裁决。
- 费用/延迟记录p50/p95、次数/Token、失败/取消/重试/缓存命中，缺Provider用量标unknown。金额用当次实际账单/价表核对，不能套旧价格。

原始输出、失败、超时、拒绝、取消、截断和重试全部保留在授权的脱敏评测目录。run_id→输入快照→Prompt版本→输出→规则/人工判断→结论可回溯；NEED_REVIEW单列，不当0分或从分母偷偷删掉。

## 4. 真实设备与体验

- 中文连续语音：耳机与外放分别；有效插话、短“嗯”、背景游戏音、自然停顿、切设备、关麦/退出。度量开口到静音和说完到首声，不能混为一个延迟。
- 看屏：用户手动授权本应用示例窗口；拒绝/选源取消/停止/换源/锁屏/恢复。记录实际帧时刻、模型理解和说话时刻，过期画面不说成当前。
- 记忆：本人愿意提供的非敏感示例，写入/新会话/新进程/更正/删除逐步验证，再看是否自然主动提起。没有新能力实现前不跑假“端到端成功”。
- 角色：现有示例与正式资产分开，能加载/有口型表情/真实协调/用户喜欢分别判断。Charakuru结构检查过不代表丰富脸部动作已满足。
- 稳定性：30分钟真实会话、挂起/恢复、正常退出和异常退出。延迟/自然度不合格则回到具体层修复，不整体换框架。

需运行时的模型/音色版本、用户系统授权和预算来自后续评审。当前真实调用数0，真实采集0；本轮没有假装完成AI评测。
