## 目标与数据流

用户启动 Aimy → 看到一个 VRM 角色 → 发送文字/图片 → AIRI 多轮会话/provider 流式回复 → 可取消 → 新进程重启恢复。

Electron stage-tamagotchi 入口 → Vue/stage-ui → core-agent/provider-inference → 聊天与 stage-ui-three 表现 → 本地会话存储。

## 任务

1. 按真实消费闭包接入桌面、UI、VRM；主进程管受限 IPC/系统能力，renderer 不开放任意 Node 能力。
2. 完成启动、模型配置、窗口拖动/显示/隐藏/重开；未启用采集时明示屏幕/麦克风关闭。
3. 多轮文字与用户分享图片，分别验证聊天/视觉 provider；流式增量、取消、超时、限流/断网和资源错误可理解。
4. 一个合法官方 VRM，基础待机/说话表现；占位可用于工程验证，但不能计为正式资产。
5. 会话、设置、窗口状态保存并用新进程重启恢复；数据删除有效，取消后陈旧输出不混入新一轮。

## 出口

目标 macOS 可复现启动、看到角色、至少三轮文字与一次图片交流、取消生成、断网降级与重启恢复。交自动化、真实 provider 记录、截图和实际耗时；缺真实模型/正式资产条件分别标待验。

C 切片尚未启用的实时语音/看屏/长期记忆不算通过。需要改变已批准范围或高风险迁移时先提交具体可审阅方案；常规适配在已授权范围内继续。
