## 2. 度量口径

- 延迟类：从动作完成（说完话/发完图）到首个可感知响应的时间，人工掐表 + 日志时间戳双记录。
- 打断类：停止耗时 = 用户开口到角色声音消失；衔接质量 = 新回答是否引用已说内容。
- 费用类：记录模型、上下文长度、每轮 token，导出账单对照。
- 不用「像真人」这类不可测表述；所有观感按 好/可接受/不可接受 三档记录，附具体现象。
