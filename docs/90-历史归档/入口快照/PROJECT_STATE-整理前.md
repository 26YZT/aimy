## 当前可使用的原型

在 digital-lover 根目录运行 `pnpm start:desktop`（首次安装/构建见 README）。窗口显示明确标注的 VRoid Sample A，可配置服务、多轮文字/图片交流、流式回复、取消生成、隐藏重开、重启恢复和清空。

设置分为“对话与识图／语音识别／语音合成”。独立配置后，麦克风持续收听，本地 VAD 确认讲话后分段转写进入会话；朗读分句合成并按序播放、驱动口型；看屏需显式选择单个源，约5秒最多观察一次，直接发布视觉文字。屏幕、麦克风和朗读默认关闭，重启/重显不自动授权。

当前语音采用连续收听＋分段 HTTP ASR＋分句 WAV TTS。“最新确认语音替换未完成旧段”会取消旧 ASR/LLM/TTS 和播放；尚不能承诺每段都被保留，或已达到原生流式识别、自然插话与扬声器回声要求。原始录音/屏幕帧默认不保存；转写/观察文字作为本地会话保存。分享图片会存入本地会话。

## 旧样机路线与尚待迁移的验收

隔离原版已按上文完成本轮范围，后续优先级以PRD 2.0对齐结果为准。以下是旧样机路线的未完成验收，供迁移参考；不直接外推为 AIRI 缺失同样能力，已有831项和43项证据不作为新基线通过。

1. 原版登录路径文字已有真实回复；BYOK、图片和ASR/TTS待验。新来源的凭证/同步/日志边界加固后，再按 [真实联调配置说明](../旧Aimy样机/运行与来源/真实联调配置说明.md) 核对服务能力与音色ID；不把旧样机安全存储通过外推到原版。
2. 在目标macOS做B/D真实链路：耳机优先，随后扬声器；记录ASR、首token、首声、插话停止、回声误识别和画面相关性/耗时。测试真实窗口/屏幕来源与系统许可、关闭/拒绝/设备变化、30分钟稳定性。
3. 根据实测修正分段替换策略、声音/口型与表现协调；正式人设、VRM/动作来源和合法音色并行评审。真实链路与人工体验通过后才判完整D出口。
4. 之后接E：主动搭话/安静/冷却、人格/情绪/关系、可纠正删除的记忆、降级和受邀安装流程；用新进程证明关系/记忆恢复。
