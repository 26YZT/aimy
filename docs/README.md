## 如何查一份旧文档

[文档台账](91-管理记录/文档台账.md)逐项记录原位置、正式位置、产物时期及日期依据、保留原因、状态、误用风险与阅读边界。精确初稿日期未知时保持未知，文件修改时间另存为文件系统元数据。

`digital-lover/docs/` 只保留旧路径跳转与证据兼容项。正文只在本目录维护。上游参考、模板和快照中的说明仍留原位，由[项目文件梳理](91-管理记录/2026-10-11-项目文件梳理.md)统一说明用途。

集中管理不等于授权公开发布。历史内部草案、来源代码、角色素材与验证附件仍须按用户范围和许可逐项审查。
